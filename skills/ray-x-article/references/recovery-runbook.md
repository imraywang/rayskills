# X Articles 恢复与验收手册

只在续写旧草稿、浏览器权限失败、上传失败、富文本异常或最终验收时读取。正文和封面始终以本地文件为准；任何恢复都回到同一草稿 URL。

## 可恢复状态

| 本地状态 | 含义 | 下一步 |
|---|---|---|
| 无 `x_article_draft_url` | 尚未建立草稿 | 进入 Drafts 查重后再新建 |
| `draft-needs-cover` | 正文已保存，封面未完成 | 打开原 URL，只补封面并重新预览 |
| `draft` | 草稿已完整验收 | 只有正文或封面发生变化时才更新 |
| `published` | 已发布 | 本 Skill 停止；不得进入编辑，交给另一个明确任务 |

本地状态表示上一次验收结果，后台可见状态决定当前是否需要修复。用户回忆与 frontmatter 冲突时，先打开已有 URL 做只读核验：封面、标题、正文和指纹都一致就不重传；只有当前后台确实缺失或本地指纹已变化才更新。

## 交付包报译介稿未过授权或署名

`prepare_article.py` 对 `kind: translation` 和 `kind: repost` 会多验一道：来源字段齐全、`source_permission` 是 `granted` 或 `open-license`、正文可见文字里有原作者和原文链接。任一不过就整体失败，交付包不生成。

不要开浏览器，也不要先建空草稿占位。缺授权时告诉用户缺的是原作者许可——联系作者、确认许可协议都是用户动作，Skill 不代发邮件，也不把沉默当默许；缺出处块时回 `ray-writer` 按 `references/translation.md` 补进正文，不在交付包或编辑器里手工加一行。

## 封面上传被拒

先分清是哪一种拒绝，两种的修法完全不同。

**一、路径不在共享范围内。** 报错说这个文件没有共享给本次会话、或路径不被接受。这是最常见的一种：封面在知识库里，而上传动作只接受用户已共享给会话的文件（会话目录、用户主动连接的文件夹）。这不是"权限没开"，开任何浏览器扩展开关都没用。

1. 立即停止重复上传，不切换到其他浏览器，不改用普通 Post 接口。
2. 确认正文、标题和现有保存状态没有被破坏。
3. 用 `record_draft.py --status draft-needs-cover` 记录当前草稿 URL、封面路径和内容指纹。
4. 把封面的**完整绝对路径**告诉用户，请用户把这个文件所在的文件夹连接给本次会话，或者把封面放到会话已经能访问的目录里。这是用户动作，不代做。
5. 用户确认后按 URL 找回原草稿，只补封面，不重新粘贴正文。

**二、点了 `Choose File` 之后卡住。** 这是操作方式错了，不是权限问题。原生文件对话框在浏览器控制能力之外，弹出来就没法收场。

1. 按 `Esc` 或按宿主的方式关掉对话框，确认页面还在原草稿。
2. 改用正确链路：读页面拿到 file input 元素引用 → 用专用上传动作把绝对路径直接交给它。
3. 之后照常等 `Edit media` → `Apply` → 验收。

两种情况都不得注入脚本绕过、不得改用普通 Post 接口、不得新建第二份草稿。

## 封面上传验收

文件选择成功不等于上传完成。必须同时看到：

- `Edit media` 裁切界面已应用。
- 编辑页出现实际封面。
- `Remove photo` 控件存在。
- Preview 出现 `Article cover image`。
- 标题、核心词和主隐喻没有被 5:2 视口裁掉。

## 富文本验收

当前 X 编辑器使用 Draft.js。只有当前页面仍符合这一结构时才使用以下只读检查；界面变化时重新观察，不猜选择器：

- 正文块：`[data-block="true"]`，列表里每个 `<li>` 各算一块
- 空白块：正文块 `textContent.trim()` 为空
- `Heading`：`h1.longform-header-one`
- `Subheading`：`h2.longform-header-two`
- 加粗：`span[style*="font-weight: bold"]`

将页面结果与交付包的 `expected_editor` 比较：

- `block_count` 完全一致。这是编辑器块数，不是 Markdown 段落数，也要在插图之前数——插进去的图会改变块数。
- `blank_blocks` 必须为 0。
- `h1_count`、`h2_count` 分别完全一致。
- `bold_count` 完全一致。
- 第一块以 `start_anchor` 开头，最后一块以 `end_anchor` 结尾。锚点是编辑器里看得见的文字，链接只剩锚文本；拿交付包的 `body` 去比会对不上，那是纯文本回退用的。

正文有插图时，再按 `images` 清单逐张核对：张数、顺序、`after_block` 位置和图片能否正常显示。

不要用整页单词数替代结构核对；X 对中文词数的显示不能证明内容完整。

## 保存与预览验收

1. 编辑页出现 `Last saved just now` 或合理的最近保存时间。
2. 打开 Preview，确认封面、标题、作者、首段、全部二级标题和末句。
3. 返回编辑页，再确认 `Remove photo`、正文格式和最近保存状态仍然存在。
4. 只有以上都通过，才把本地状态从 `draft-needs-cover` 更新为 `draft`。

整个过程中不得点击 `Publish`。登录恢复、文件权限恢复和重连浏览器只恢复原草稿任务，不产生公开发布授权。
