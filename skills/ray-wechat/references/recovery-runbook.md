# 公众号草稿恢复手册

| 症状 | 原因 | 恢复动作 |
|---|---|---|
| 草稿箱出现同题多份 | 未读取本地 media ID 或先新建后查重 | 停止创建；使用 frontmatter 的 ID 更新原草稿 |
| 中文变成 `Ã¥...` 或 `å...` | HTTP 响应被错误解码后又写回 | 用本地正确 HTML 覆盖正文；标题取 frontmatter；摘要取明确文案；强制 UTF-8 回读 |
| 标题正确但正文乱码 | 只核对 API 成功码，没有检查正文 | 回读首句、末句和全部原文块；不通过就更新同一草稿 |
| 封面丢失 | 更新请求没有保留 `thumb_media_id` | 先 `draft/get` 读取原封面 ID，再更新原草稿 |
| 排版有大段空白 | Markdown 连续空行或 HTML 空 `<p>` | 回到本地清理并重跑 `prepare_article.py` |
| 全文太单调 | 只有普通段落和统一字号 | 增加章节、三项导读、少量金句和关键判断标记，不堆色块 |
| 英文词被下划线截断 | 自动选重点按字符窗口切分 | 重点只取完整中文短语或完整英文 token，重新生成 |
| 文末出现作者占位或三连 | 排版器自动附加签名组件 | 按用户署名策略整块删除，重新生成预览和正文 |
| API 报 IP 白名单或权限错误 | 固定出口未在公众号白名单，或账号缺接口权限 | 保留本地交付包，按下面「IP 白名单」一节核对固定地址；不改用动态出口或 `freepublish/*`，不扩大授权 |
| 更新后验证数量不一致 | 微信清洗了不兼容标签或遗漏原文 | 比对原文块、章节、空段落与重点数量；修正 HTML 后更新同一 ID |
| 某张正文图片路径错误 | 上传前没有核对全部本地资产 | 停止远端操作，先跑 `wechat_images.py --dry-run` 校验清单；全部通过后才正式上传 |
| 正文图片报 40005／45002 | 图片格式或体积超出 `media/uploadimg` 限制 | 让 `wechat_images.py` 转码（需要 Pillow），或换一张 1MB 以内的 jpg/png；不要手工改 HTML 里的 `src` |
| 真机上样式与本地预览不一致 | 微信给未声明的属性注入了自己的默认样式 | 定位被注入的标签，在 `references/ray-themes.json` 里把该属性显式声明（含 `border:none;`、`text-align:left;`）后重排重传 |
| 交付门报译介稿授权或署名未过 | 译文授权还没拿到，或出处块没进正文 | 停在本地产物。缺授权时说清缺的是原作者许可——联系作者、开公众号转载白名单都是用户动作；缺出处块时回 `ray-writer` 按 `translation.md` 补，不在 HTML 里手工加一行 |
| 出处链接只在 `href` 里（提醒） | 出处块用了 Markdown 超链接 | 公众号正文外链多数账号点不开。把原文地址改成纯文本再重排；这条不拦草稿，但读者拿不到出处 |

## IP 白名单

公众号接口默认走已确认的固定出口。配置位于 `~/.wewrite/fixed-egress.json`，当前 SSH 主机别名为 `zgo-standard`，预期公网地址为 `23.165.40.62`。

1. 脚本会在获取 token 前建立固定通道，并用外部服务核对实测公网地址。通道失败、配置缺失或地址不是 `23.165.40.62` 时立即停止。
2. 若通道核对通过但微信仍报 `40164`，确认报错中的地址也是 `23.165.40.62`。
3. 只有固定地址不在白名单时，才请用户在公众号后台「设置与开发 → 安全中心 → IP 白名单」添加该地址。这是账号安全设置，属于用户动作。
4. 用户确认后原地重试同一条命令，不跳过 `prepare_article.py`、`wechat_images.py` 或完整回读。
5. 直连只允许在用户当前任务中明确要求时通过 `RAY_WECHAT_DIRECT=1` 临时启用；不能作为固定通道失败后的自动回退。

固定通道只解决稳定出口，不产生草稿写入授权，也不允许换成发布接口。

## 乱码修复完成标准

不能只把标题修回来。必须同时确认：

1. 标题和摘要是正确中文。
2. 正文首句、末句和所有原文块按顺序存在。
3. 封面 ID 与修复前一致。
4. 章节、重点样式和空段落数量符合交付清单。
5. 署名策略仍然生效。

## 失败时如何汇报

说明当前停在哪一层：本地排版、授权、接口写入或回读验收。不要把“请求已发送”描述成“草稿已完成”，也不要把需要用户处理的白名单问题说成内容错误。
