# 四层质量闸门

每层都必须通过。不能用语言精彩抵消事实薄弱，也不能用事实很多掩盖文章难读。

## 第一层 真实性

- 核心事实是否能回到原始来源。
- 人物观点是否明确归属，没有写成客观事实。
- 最新状态、数字、日期、职位和产品规则是否重新核对。
- 作者推论是否能指出依据。
- 用户经历、对话、情绪、耗时、成本和结果是否来自真实材料。
- 反例和不确定性是否被诚实保留。

任一核心事实无法核对，就降低语气、删除或暂停交付。

## 第二层 文章性

- 开头是否出现具体变化、人物、实践或冲突。
- 原材料若有清楚转向，开头是否已经直接进入“人物—阻力—决定”，还是先用几段背景替读者解释为什么值得看。
- 全文是否围绕一个核心问题推进。
- 每一段是否带来新事实、新机制、新反方或新判断。
- 关键判断之前是否已经出现足够强的证据；是否存在先讲完道理、后面才补案例的问题。
- 技术材料和来源是否已经退到幕后，正文呈现的是作者消化后的判断。
- 段落长短是否有节奏，是否存在报告腔和提纲腔。
- 篇幅是否偏向最强证据、真实反方和最终判断，而不是把背景、方法、风险和结尾平均分配。
- 章节是否像一个人在连续思考，还是能看出若干正确模块被拼在一起。
- 反方是否指出具体失效机制，而不是一句“也有局限”或“存在幸存者偏差”。
- 结尾是否完成判断升级，而不是总结目录；若用问句收尾，作者是否仍留下了自己愿意承担的判断。
- 是否存在重复收束、每节都总结一次、结尾又重列全文的问题。
- 与最近一两篇认可文章相比，是否同时重复了开场入口、推进顺序和收尾动作；若重复，是否只调整了一个最自然的维度。
- 结构是否符合所选原型。
- 面向公众号或 X 的长文，是否有足够但不过量的二级标题作为阅读锚点；标题是否由文章推进自然产生，而不是按字数机械分段。
- 是否只加粗真正需要读者停一下的关键问题、冲突、行动门槛或判断；只扫加粗内容时能否看出文章路线；是否避免为了达到固定数量而加粗。
- Markdown 段落之间是否只留一个空行，没有连续空行造成的空白段落。

标题和加粗是浏览导航，不是装饰。标题应该让只扫一遍的人也能看出论证如何推进；加粗内容可以是完整判断，也可以是关键问题或行动门槛，但单独扫到时必须有意义。数量只能作为提醒，不能盖过文章本身的节奏。

结构稳定不算失败。只有连续文章同时重复开场、推进和收尾，读者已能提前猜到文章怎么走时，才需要变化。价值和清楚始终优先于形式新鲜。

## 第三层 情绪与传播

- 开头是否让读者很快感到一个真实矛盾、变化或代价。
- 中段是否让问题自然加深、发生修正或出现新的理解。
- 情绪是否有起伏，而不是全程一个音量。
- 是否有一到三句自然长出来、可独立传播且仍然准确的表达。
- 网感是否来自自然口语和当下语境，而不是热词拼贴。
- 结尾是否有情绪余波。

情绪不足时，回到矛盾和代价，不靠增加感叹号或补画情绪曲线。传播句不足时，重新压缩核心判断，不单独制造金句。

## 第四层 个人语气

- 是否像一个做过事情、愿意承担判断的人。
- 是否平视读者，不装导师或品牌公关。
- 是否保留 Ray 的清楚、克制和证据意识。
- 是否有真实立场，而不只是把资料组织得很顺。
- 是否误用了别人的口头禅、人设和经历。
- 删除署名后，是否仍能看出独特判断。

## 机械检查后的人工复核

`article_check.py` 只能发现篇幅、格式、模板词、过度重复和部分节奏问题。它无法判断事实是否真的可靠，也无法证明一句话有传播力。

检查结果分两类：

- 错误：必须修改后才能交付。
- 提醒：必须逐项判断，确认合理才能保留。

先完成自然语言自修，再运行检查器。最终交付前从头朗读一遍；读不顺的地方直接改，不用“这是书面语”替它辩护。提醒可以在人工判断后合理保留，不以清零为目标。
