# 咨询报告视觉

## 视觉风格原子

创作一张高端管理咨询报告式视觉封面。风格核心是“文字主导 + 标题结构重构 + 单一商业隐喻 + 瑞士现代主义网格 + 克制但完整的封面层次 + 专业配色”。

这不是普通 PPT、解释型信息图或粗体自媒体封面。观众首先看到经过设计重构的核心词，其次才看到完整标题和商业隐喻。图形必须从文字结构中生长，而不是作为独立图表摆在标题旁边。

## 风格基因

- 麦肯锡式理性气质、高端报告封面感、瑞士现代主义网格和 boardroom-ready 的信息层级。
- 白底或极浅冷灰底，保留大面积干净留白，但留白必须经过设计；使用可见但克制的网格、透视线、坐标、轮廓、阈值或分析标注组织空间。
- 使用页眉、页脚、细边框、报告索引、年份、章节标签、坐标刻度等少量版式家具建立报告感，但不得形成内容页。
- 画面只使用一个核心商业隐喻，例如战略路径、阈值、防线、断层、坐标、收束点、窗口、矩阵边界或价值阶梯。
- 图形应简洁精准，只保留极细结构线、少量节点、一个方向箭头或一个关键强调点，不展开为完整说明结构。
- 配色以白、深蓝、冷黑、冷灰、银灰为主；最多使用一种少量蓝、橙、红或绿作为决策点、风险点或终点强调。

## 封面信息密度

- 封面只保留一个主视觉核心词、一个商业隐喻、一个完整但克制的小标题系统和极少量标签。
- 必须有明确而单一的视觉中心，信息量克制，留白充足，但画面不能只剩一个孤立词语和空白背景。
- 用户提供的完整标题或副标题必须作为清晰可见的 B 层出现，不能省略或缩小到无法承担语义。
- 背景至少建立一套连续的细线空间系统，例如单点透视线、同心风险轮廓、断层线、坐标轴、构造网格、路径残影或少量分析标注；这些结构应覆盖并连接画面，而不是零散装饰。
- 可以围绕同一个隐喻放置 2–4 个极短的背景注释或坐标标签，但它们不能组成步骤列表、卡片模块或流程。
- 不要把文章的章节、步骤、观点清单或分析框架全部画出来。
- 不要生成三步、四步、五步流程，不要展开完整漏斗、矩阵、仪表盘、路线图或节点时间线。
- 如果画面看起来像在“解释方法”，而不是在“提出一个高级商业观点”，说明已经偏离该风格。

## 长标题分层

当用户提供较长标题时，必须拆成三层：

1. A 层 / 主视觉核心词：
   - 从完整主题中提炼 2–8 个最有张力、最适合结构化重构的中文字符。
   - A 层可以很大，但字重必须克制，避免粗黑、压迫和社媒海报感。
   - A 层承担画面的商业隐喻。
2. B 层 / 完整标题：
   - 完整保留用户输入标题。
   - 放在页眉、边缘信息栏、副标题区或报告标题带中。
   - 字号明显小于 A 层，清晰可读但不争夺视觉中心。
3. C 层 / 报告标签：
   - 只保留 1–3 个极短标签、年份或栏目索引。
   - 像咨询报告版式系统的一部分，不做徽章、按钮或社交媒体标签。

不得为了“主标题完整”而把整个长标题做成一块巨型粗黑文字。完整性由 B 层承担，视觉冲击由 A 层承担。

## 图文关系

- A 层核心词必须成为画面主体结构，而不是普通标题。
- 根据语义对文字做切割、镂空、错位、分层、收束、路径化、框架化、矩阵化、断层化或空间化重构。
- 战略路径可以进入字形内部，断层可以切开笔画，坐标可以成为字的骨架，窗口可以出现在负空间中，收束线可以从字中延伸到单一消失点。
- 商业隐喻必须嵌入文字，改变字形结构或从字形中生长；禁止在普通标题旁边另放一个独立图标、泡沫、流程图或矩阵。
- B 层完整标题和 C 层标签像报告封面小字系统，数量克制、层级明确。

## 字体行为

- 中文使用现代黑体、宋黑混合或克制的现代无衬线气质；英文使用 Helvetica、Neue Haas Grotesk、Univers 或 Swiss-style sans-serif 气质。
- 主视觉文字可使用常规至中等字重、细线字、半镂空字、结构字或轮廓与实体混合字。
- 字体可以巨大，但不能过度粗黑、过度压缩、形成沉重文字墙或廉价标题党视觉。
- 优先通过结构、空间、尺度、负空间和透视制造张力，而不是依赖 extra-bold 字重。
- 保持中文准确、完整可辨，不使用乱码、伪字或破坏识别的过度扭曲。

## 空间与构图

- 优先采用宽阔的横向报告封面结构、严格网格和大面积负空间。
- 可使用单点透视、远处收束点、薄片式空间层、细线坐标或从文字底部延伸出的路径，建立理性而具有方向感的空间。
- 背景结构线必须达到可感知的视觉存在：主网格、次级透视线、风险轮廓和边缘刻度共同构成完整空间，而不是只留下极淡、几乎看不见的辅助线。
- 允许用半透明同心圆、波纹、弧线或泡沫边界暗示风险与预期扩张，但必须与标题字形、路径或坐标系统发生结构关系，不能成为孤立插图。
- 允许将 2–4 个文章核心维度作为极小注释散布在同一坐标场中，例如技术突破、行业复制、组织采用、商业兑现；它们是背景分析标注，不是四步流程。
- 视觉隐喻只有一个；其余结构线只用于建立秩序。
- 图形必须服从标题，不能把画面切成多个同等权重的模块。
- 页眉、页脚和边缘信息带可以存在，但必须轻、薄、小、准。

## 色彩与质感

- 主色：白、深蓝、冷黑、冷灰、浅灰、银灰。
- 强调色只选一种，并且只用于一个风险点、决策点、价值点、终点或关键箭头。
- 禁止大面积高饱和暖色、蓝紫霓虹、赛博朋克光效、彩虹渐变和广告式发光。
- 使用干净哑光纸面、轻微印刷颗粒、精准细线和极淡空间阴影；避免玻璃拟态、塑料 3D 和通用科技 HUD。

## 风格特有禁用项

- 不要生成虚假详细数据、虚构复杂图表或密集小字。
- 不要把完整长标题作为巨型 extra-bold 文字块。
- 不要使用粗黑、拥挤、压迫性的社交海报标题。
- 不要把封面做成三步以上流程、节点时间线、完整漏斗、完整矩阵、仪表盘或方法论说明页。
- 不要让结构图抢走标题层级，也不要让图形和标题彼此独立。
- 不要堆放大量图标、箭头、节点、标签、模块或说明文字。
- 不要让一个孤立核心词漂浮在近乎空白的背景中，也不要省略用户要求的完整标题或副标题。
- 不要使用廉价商务模板、握手照片或无关办公场景。
