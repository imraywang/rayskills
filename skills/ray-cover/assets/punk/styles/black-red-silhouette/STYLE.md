# 黑红剪影

## 视觉风格原子

创作一张黑红剪影风格封面。整体只使用红、黑、白三种颜色：红色负责空间和情绪，黑色负责主体和剪影，白色只用于标题、少量高光和关键点睛。画面必须极简、干净、有冲击力，像一块巨大的红色舞台屏幕，主体像舞台动画里的黑色图形符号。

## 风格基因

- 只使用红、黑、白三种颜色。红色占主要面积，黑色形成主体轮廓，白色只做标题、少量高光和关键点睛。
- 背景是大面积纯红空间，不使用复杂背景、杂色、渐变、做旧、纸张颗粒、脏污纹理或复古磨损。
- 每张图只保留一个核心场景、一个主体动作和一个清晰隐喻。
- 主体必须以黑色剪影为主，轮廓清楚，细节克制，不表现写实人物脸，不追求真实摄影感。
- 主体场景必须比文字更重要，远看先看到黑色剪影和红色空间，近看再读标题。
- 工具教程类优先使用“人正在使用工具”的场景表达。
- 电影主题类优先使用最经典的人物姿态、关系或标志性场景表达。
- 金融主题类优先使用牛、曲线、上升结构、观察者等简洁符号表达。
- 速度主题类优先使用车辆、道路、远方城市、速度线表达。
- AI 主题类优先使用人、屏幕、脑形符号、光标或极简界面表达。
- 不为了设计感强行加入大手、锁链、机械流水线或复杂装置；只有这些元素和主题高度相关时才使用。

## 图文关系

- 主标题使用白色或暖白色，字体清晰、简洁、有力量。
- 标题必须清楚可读，但保持克制，只作为辅助信息，不成为画面主角。
- 副标题比主标题小一档，只作为补充说明。
- 除主标题和副标题外，不出现其他文字，不做信息图，不堆说明文字，不出现复杂 UI 文案。
- 横版封面中，标题放在居中偏左或居中偏右，根据主体位置避让；主体场景必须是第一视觉。
- 竖版封面中，标题放在最上方居中或最下方居中，不占据过多空间；中间主体必须成为绝对主视觉。
- 中文使用现代黑体、几何黑体、粗黑体或窄体黑体；英文使用清晰有力的 sans-serif、grotesk 或 condensed sans-serif。

## 风格特有禁用项

- 禁止出现蓝色、紫色、绿色、棕色、灰脏色、金属色或任何额外杂色。
- 禁止复杂渐变、霓虹光效、赛博蓝光、真实摄影感、过多 UI 面板和复杂信息图。
- 禁止复古做旧颗粒、脏污纹理、纸张颗粒、磨损边缘或仿旧印刷效果。
- 禁止复杂背景、复杂人物五官、写实人脸、装饰性细节堆叠。
- 禁止让文字压过主体画面，或让文字成为唯一主视觉。
