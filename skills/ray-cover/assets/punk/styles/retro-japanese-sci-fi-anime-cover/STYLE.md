# 复古日本科幻动画

## 视觉风格原子

创作一张具有 90 年代日本科幻赛璐璐动画关键帧感的封面。风格核心是标题卡式第一视觉、强烈限色、高饱和纯色色块、锋利手绘线稿、硬边赛璐璐阴影、夸张透视、强烈明暗对比和轻微胶片颗粒。可以借鉴复古科幻动画标题卡、紫绿机甲配色和赛璐璐质感的视觉语言，但不能复制任何既有作品的角色、机体、标志、标题或具体场景。

## 风格基因

- 先理解主题的核心矛盾、情绪和动作，再转化为 1 个核心隐喻、1 个主要主体和 1 个正在发生的动作。
- 每张图只允许 1 个视觉中心、1 个核心隐喻、1 个主要主体和 1 个主要动作；删除会分散注意力的第二概念。
- 画面必须具有高饱和纯色色块、锋利手绘线稿、硬边赛璐璐阴影、夸张透视、强烈明暗对比、轻微胶片颗粒和复古动画关键帧感。
- 只从以下颜色中选择：深紫色 #5F2A62、荧光绿色 #8BD450、深蓝黑色 #1D1A2F、警示黄色 #F5C024、亮紫色 #965FD4、经典橙色 #F47A16、少量黑色和米白色。
- 每张图只使用 1 个主背景色、1 个次级主色和 1 个小面积强调色；不要平均使用全部颜色，不要增加其他颜色，不要大面积渐变。
- 自动判断主体类型时，人物、心理、情绪、关系、社会、成长类主题优先使用人物；AI、工具、技能、系统、方法、代码、产品、知识类主题优先使用无人物画面，或人物与装置交互。
- 有人物时，人物必须处在明确动作和处境中，例如挣脱、拉扯、切断、穿越、推动、阻挡、启动或重组；不要静止摆拍，不要复制既有动画角色造型。
- 无人物时，不能出现人物、人体剪影、手部或人脸；使用代码、页面、文件、卡片、模块、装置或空间结构表达主题，并表现展开、转化、爆发、拼合、穿越、启动或重组。
- 无人物画面不要只放静止图标、圆环、门、立方体或代码符号；主体结构必须正在变化。
- 只有主题涉及循环、持续迭代、长期主义、无限可能或自我进化时，才允许使用 infinity 符号；它必须成为场景结构、运动轨迹或系统闭环的一部分，不能只是装饰。
- 构图必须根据画幅比例重新设计，不直接裁切同一张图。横版优先左标题右画面或右标题左画面，强调横向运动和空间纵深；方形或 4:3 使用上下错位或对角穿插；竖版优先上标题下画面、侧边纵排标题或主体沿纵向空间运动。

## 图文关系

- 主标题必须是第一视觉，准确、完整、清晰可读，不能贴边；缩小后仍能看清。
- 中文标题使用修长、锋利、高对比的明朝体、宋体或 Mincho 风格；英文标题使用 Didot、Bodoni 或 Mincho 式高对比衬线体。
- 标题可以分行、纵排、错位或与画面穿插，但不能牺牲字形识别；标题气质应接近复古科幻动画标题卡，而不是普通黑体、圆体或现代 UI 字体。
- 除主标题外，最多只允许 1 行副标题或 1 行极小英文短句。
- 不要出现编号、日期、版本号、条形码、参数、步骤列表、信息卡片、大量小字或复杂 UI。
- 所有文字处于安全区域，关键动作不被裁切，画面只保留一个视觉中心。

## 风格特有禁用项

- 不要 3D、摄影写实、现代赛博朋克、普通扁平插画或企业科技风。
- 不要复制任何具体动画作品的角色、机体、标志、标题、台词或具体场景。
- 不要使用普通黑体、圆体、现代 UI 字体或弱标题层级。
- 不要平均使用全部固定颜色，不要添加其他颜色，不要使用大面积渐变。
- 不要静止摆拍、无动作主体、装饰性符号堆叠或多个视觉中心。
- 不要让辅助信息超过一行，不要用复杂 UI 或大量小字解释主题。
