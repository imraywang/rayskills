# 复古油墨点阵隐喻

## 视觉风格原子

创作一张“复古油墨打印机 + 极简点阵隐喻”风格的封面海报。画面像复古科技杂志封面、旧式打印说明页或极简编辑海报：浅暖灰米色平底、深黑油墨铅字、偏小的黑色点阵插图、固定留白和克制信息层级。稳定性高于风格发挥，不能因为主题不同而改变字体、颜色、字号比例、版式结构或插图体量。

## 风格基因

- 背景固定为纯色浅暖灰米色 `#DED9CF`，必须平整、统一、干净；不得偏黄、偏白、偏灰、偏粉，不得出现渐变、光影过渡、明显纸纹、大面积噪点、做旧污渍或局部脏污。
- 主标题与插图固定使用深黑色 `#111111`；底部短词固定使用深灰色 `#343434`；整张图只允许这三种颜色，不新增第四种颜色。
- 所有文字使用同一套复古油墨机械铅字字体。字形略窄、方正、机械、稳定，带轻微油墨扩散和老式打印不均匀感，像旧式打字机、铅字报刊、档案标题。
- 主标题使用该字体体系的粗体版本；底部短词使用同一字体体系的细体版本。不要换成现代几何黑体、像素字体、宋体、书法字体、手写字体或夸张破损字。
- 标题字号按画幅固定，不因标题长短自动放大或缩小；主标题最多两行，不得压满画面，也不得为了填满文字区而变大。
- 底部短词字号固定为主标题字号约 23%，字距约为正常字距的 1.15 倍；最多 3 组短词，用中点分隔；用户未填写时留空，不自动补词。

## 图文关系

- 横版比例 `5:2`、`16:9`、`3:2`、`4:3` 使用左文右图结构。左侧文字区约占画面宽度 52%，右侧插图区约占 22%-26%；主标题在左侧文字区中上部，底部短词在左侧底部，插图在右侧中部并垂直居中。
- `5:2` 横版中，主标题文字框宽度固定为画面宽度的 38%-42%，左边距为画面宽度的 7%-9%，主标题总高度不得超过画面高度的 24%，上下留白必须充足。
- 方形与竖版比例 `1:1`、`4:5`、`3:4`、`9:16` 使用上文下图结构。主标题位于上方偏中区域，插图位于中下部，底部短词位于最下方安全区域。
- 文字区与插图区之间必须保留明显空白。插图必须偏小，不喧宾夺主；横版保持右侧小主体，方形与竖版占画面高度约 25%-32%。
- 画面中只允许出现一个主标题、一个极简隐喻插图、一组可留空的底部短词。不要显示主题说明、隐喻解释、备注、功能列表、编号、标签、副标题、大段正文、额外英文说明、水印、Logo 或二维码。

## 隐喻与插图

- 先理解主题核心意思，再提炼一个最简单、最直接、一眼可识别的视觉隐喻。每张图只保留一个核心主体，或两个物体之间最简单的关系。
- 插图只使用黑色圆点、稀疏线性点阵和少量油墨网点构成，像寥寥几笔完成的点阵速写。
- 主体只保留外部轮廓、一个主要动作、一至两个身份特征；不刻画复杂材质、复杂背景、复杂阴影、过多内部零件、无关小物件或场景叙事。
- 插图必须明确但不能复杂，宁小勿大，宁简勿繁。

## 风格特有禁用项

- 不要高饱和颜色、渐变、发光、3D、写实摄影、复杂背景或大面积做旧污渍。
- 不要自动添加说明文字，不要自动改变字体，不要自动放大标题。
- 不要让插图过大，不要让画面过满，不要堆叠多个概念或多个主体。
