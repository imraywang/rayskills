# 彩色新构成主义巨构海报

## 视觉风格原子

创作一张具有巨构感、震撼感和强烈几何张力的彩色新构成主义海报。风格核心是巨大主体、极端尺度差、锐利方向动势、高反差色块、克制文字和复古印刷质感。

## 风格基因

- 一张图只保留 1 个核心主题、1 个核心主体、1 个视觉中心、1 个主要运动方向、1 个核心隐喻和 1 套独立配色。
- 主体必须形成巨大压迫感，占据画面 40%-80% 面积，或被画面边缘大胆裁切，或与小型陪体形成极端尺度反差。
- 优先使用巨大圆弧压入画面、超大主体局部特写、对角线切割、强透视延伸、环绕式构图、向中心汇聚、向上压迫或纪念碑式边缘裁切。
- 几何元素包括巨大圆形或圆弧、三角形、楔形、长条色块、放射线、轨迹线、重复细线、锐利切面、大面积纯色背景和深色留空。
- 几何元素必须承担空间、节奏、方向和压迫感，不作为装饰堆叠。
- 主体可以适度几何化、平面化、符号化、剪影化、局部放大、比例夸张和结构强化；必须清晰可识别，但不追求繁琐细节。
- 人物保留识别度最高的轮廓、姿态、侧脸、半身或局部特写；产品可放大、裁切、旋转、拆分或夸张透视；建筑强化高度、体块、边缘和纪念碑感；动物保留关键轮廓与动作；天体优先做成超大局部或巨大圆弧；抽象概念转化为单一清晰隐喻。
- 每次重新建立一套 3-4 种主要颜色的大胆限色系统：1 种主色占 50%-70%，1 种爆点色集中用于关键主体、标题或几何切面，1 种深色稳定结构，1 种浅色用于文字与留白。
- 色彩可以冷暖强碰撞、明暗强碰撞、高低饱和碰撞、互补或近互补碰撞、脏色与亮色并置、复古色与跳色并置。目标是大胆、陌生、冲突但成立。
- 可参考但不要固定使用：暗紫 x 黄绿色 x 陶土橙 x 米白，宝蓝 x 桃红 x 橄榄绿 x 浅米色，深棕 x 湖蓝 x 芥末黄 x 奶油白，酒红 x 青绿 x 土黄 x 炭黑，灰紫 x 橙红 x 脏绿 x 象牙白，深蓝 x 珊瑚粉 x 沙黄 x 黑色，墨绿 x 荧光黄绿 x 灰粉 x 米白，赭石 x 雾蓝 x 淡金 x 深紫黑。
- 加入克制的复古印刷质感：细微纸张颗粒、丝网印刷网点、轻微油墨不均、极轻微套色偏移、自然褪色和细小印刷纹理。

## 图文关系

- 画面最多保留主标题 1 处、副标题最多 1 处、辅助信息最多 1 处；辅助信息控制在 8 个汉字以内。
- 文字总面积不超过画面 15%，主标题承担第一视觉或与主体共同承担第一视觉。
- 主标题使用粗体、窄体、压缩字体或几何字体，可以巨型放大、局部裁切、纵向排列、沿几何边缘排列、与主体咬合、沿圆弧或斜线布局、穿插在前景与背景之间。
- 标题要像画面结构的一部分，而不是单纯贴在背景上。
- 阅读顺序必须明确：主标题、然后副标题、最后辅助信息。

## 风格特有禁用项

- 不要让主体以正常大小摆在画面里。
- 不要平均分布颜色面积。
- 不要连续套用固定黄色背景或固定色组。
- 不要堆叠多组辅助文案或扩展成长说明。
- 不要把几何元素当作无意义装饰。
- 不要制造多个视觉中心、多套隐喻或多条主要运动方向。
