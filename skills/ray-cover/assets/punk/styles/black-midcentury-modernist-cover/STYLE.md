# 黑色复古现代主义封面

## 视觉风格原子

创作一张黑色复古现代主义编辑插画封面。整体采用 20 世纪中期现代主义复古书封、复古杂志封面、黑色电影和几何平面设计语言。画面黑色占主导，气质复古高级、理性克制、简洁鲜明、几何概括，并具有强烈封面感。

## 风格基因

- 全图严格控制在 3 种颜色以内：黑色作为绝对主色，白色或米白色作为辅助色，只允许 1 个鲜明点缀色。
- 黑色应占据大部分背景或主体，形成明确的黑白关系和复古电影感。白色或米白色用于标题、人物肤色、主体局部、高光或少量排版信息。
- 点缀色只能从红、绿、蓝、橙、紫或黄色中选择一种，并且只用于局部主体、标题重点字、几何图形或少量强调元素。不要同时出现多个亮色。
- 根据主题自动选择最有代表性的核心画面，不固定为侦探、电影、泰式按摩或任何单一题材。
- 每张图只保留一个核心主体、一个视觉中心、一个主要色彩重点和一组主标题信息。主体与文字比例协调，结构清楚，不堆满画面。
- 主体使用几何化轮廓、扁平大色块、剪影式明暗、简化五官与细节、少量夸张比例和复古编辑插画表现。
- 人物、产品、建筑、动物、机器人、服务场景或抽象概念都要被概括成清晰、简洁、容易识别的视觉符号。
- 可以加入克制的复古纸张颗粒、丝网印刷、旧书封或轻微油墨磨损质感。质感必须轻微，不能脏乱、严重褪色或降低清晰度。
- 画面必须满版出血，四边内容直接延伸到画布边缘。不要白色边框、卡片式外框、圆角白边、四周留白或外圈浅色包边。

## 图文关系

- 主标题必须醒目，是画面的第一视觉中心之一，并与主体共同形成封面主结构。
- 中文主标题使用有力量感、书封感或编辑感的字体，可偏粗重宋体、标题宋、几何黑体或复古招牌式字体；英文副标题可使用优雅衬线体或简洁大写字体。
- 辅助文字尽量少，只保留必要信息。除主标题、副标题和一个辅助短句外，不出现其他说明文字。
- 根据画幅比例自适应安排构图，可选择左图右字、左字右图、中心主体两侧信息、上下分区或偏单主体海报式构图。
- 横版封面可用大面积黑色负空间承载标题，让核心主体在一侧形成清晰戏剧关系。竖版封面应让标题和主体上下或中心错落，保持书封式秩序。
- 标题必须清楚可读，避免被主体遮挡、纹理吞没或装饰元素干扰。副标题与辅助短句应明显弱于主标题。

## 风格特有禁用项

- 禁止霓虹赛博风、现代科技蓝紫渐变、多彩配色、复杂光效、玻璃质感、金属 3D 和普通互联网宣传海报感。
- 禁止使用多个亮色、高饱和多彩、复杂渐变或额外杂色。
- 禁止写实摄影、3D 渲染、动漫风、复杂机械细节、大量无关装饰和密集背景。
- 禁止大量标签、参数、图标、编号、说明文字、复杂 UI 面板和信息过载。
- 禁止白色边框、卡片式外框、圆角白边、四周留白和外圈浅色包边。
