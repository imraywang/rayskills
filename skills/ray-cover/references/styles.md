# 选风格

风格库是 Punk 的 MIT 版（`assets/punk/`，31 个封面风格，目录见 `assets/punk/punk-cover/references/style-catalog.md`）。每期只用一个风格，不混。

## 默认三选一（2026-10-13 Ray 认可的方向）

| 风格 | style id | 适合 |
|---|---|---|
| Anthropic Research 风格 | `anthropic-research-style` | AI、研究、知识、系统类；纯色底 + 衬线标题 + 一条抽象线条隐喻，最克制 |
| 黑白灰先锋几何 | `black-white-gray-avant-geometry` | 工具、机器、构造、冲击力强的题；超大标题 + 几何主体 |
| 纸面击凸压凹封面 | `paper-emboss-deboss-cover` | 方法、写作、设计、观点；纸纤维 + 凹凸印，艺术书质感 |

按内容挑一个；拿不准时用 Anthropic Research。

## 按内容可以换的

- 观点、哲学、批判：`black-white-minimal-concept` 黑白极简概念、`black-white-etching-editorial-cover` 黑白复古蚀刻版画
- 技术、AI、系统：`retro-ink-dot-matrix-metaphor` 复古油墨点阵隐喻、`minimal-visual-metaphor` 极简视觉隐喻
- 商业、创业、公司：`business-magazine-front-page` 商业杂志头版、`black-midcentury-modernist-cover` 黑色复古现代主义
- 一个短词要视觉化：`semantic-minimal-translation` 语义转译极简
- 关系、变化、过程：`layered-paper-cut-concept-poster` 立体纸雕概念海报

彩色风格（彩色新构成主义、复古弥散渐变、复古日本科幻动画、方块 / 积木世界）和 IP 冲突，除非 Ray 点名不用；用了也按 `ip.md` 收成黑白灰 + 墨绿。
