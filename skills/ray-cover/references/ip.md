# Ray 的 IP 约束（写进每一条封面提示词）

和视频签名层同一套（见 ray-explainer 的 `references/ip-style.md`）：个性色是黑白灰，记号色墨绿 #054C4C（取自 Ray 形象的底色）。

- **颜色**：画面只用黑、白、灰阶，加一个墨绿 #054C4C；墨绿只出现一处，指向最重要的那个点（一个点、一条线、一个字的局部、一个小物件）。风格本身带别的颜色（黑红剪影的红、银色锡纸的蓝、OSB 的木色和工业蓝、复古弥散渐变的彩色）时，把那个颜色换成墨绿或灰阶，同时保留风格的材质和构图。真实材料本身的颜色（纸、木、金属）按灰阶处理。
- **禁用**：蓝紫渐变、霓虹、发光、科技蓝、漂浮 UI 卡片、机器人和发光芯片当 AI 符号、电商广告感、PPT 感、装饰性英文大字。
- **形象**：默认不画 Ray 的形象。Ray 要求加时，用 `~/.config/ray-explainer/avatars/ray/base.png`（黑卫衣、墨绿底的扁平贴纸卡通）作参考图（`codex exec -i`），按所选风格的画法重绘进画面，或者在角落放一枚墨绿圆形印章；不贴原图。
- **写进提示词的方式**：放在蓝图的「Color, Material, and Texture」和「Negative Constraints」两节里，用描述性的话写清楚，不只写色值。
