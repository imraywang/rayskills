# 解说稿规则（script.json）

## 结构

```json
{
  "title": "片名", "source": "素材路径或 URL", "header": "一篇读懂 · 主题",
  "theme": "ray-ip",
  "host": { "avatar": "ray", "big": [] },
  "voice": "ray", "speed": 1.1,
  "gaps": { "lead": 0.6, "line": 0.32, "scene": 0.8, "tail": 1.6 },
  "scenes": [
    { "id": "hook", "sig": true, "lines": ["第一句", "第二句"] },
    { "id": "list", "grammar": "y5_kinetic_type", "lines": ["……"], "cues": [] }
  ],
  "chapters": [],
  "to_confirm": ["编补或存疑的说法，交付时列给 Ray"]
}
```

- 以上就是 `assets/template/script.template.json`，`new_project.sh` 拷的就是它。`voice` 默认 `ray`（复刻音色，走 fal），没注册时改成 Gemini 预置音色如 `Charon`；`host` 是左下角主持人（IP 默认），`big` 留空不调 Kling；`sig: true` 是墨绿签名幕；`chapters` 只在 HyperFrames 模式按章节分段，kit 模式忽略它、顶部画一条连续进度条；一期混用多种画法时才在顶层加 `"mix": true` 并写理由。
- `id` 只用英文小写。kit 场景和 `scenes.js` 里的 `S.<id>` 一一对应；语法场景另写 `grammar` 和 `cues`，见 [grammars.md](grammars.md)。完整范例：`assets/template/script.example.json`。
- 每句 12–50 字。估时统一按每秒约 5.8 字 × `speed`（不含停顿，和 `storyboard.py` 一致；实测 Charon 约 5.7、Ray 复刻音色约 6）。2.5 分钟大约需要 750–800 字、25 句左右。
- 场景数 7–10 个，每场 1–4 句。一个场景只讲一件事、只配一个主画面。

## 写法（来自 Ray 的写作规则）

1. **表达先行**：用 Ray 本人的口吻把判断说满，不写“可能”“某种程度上”“值得注意的是”。
2. **正文不自保**：拿不准、编补、夸张的内容照样写进稿子，但必须同时记进 `to_confirm`，由 Ray 决定去留。
3. **贴合大陆观众**：例子和说法用国内观众熟悉的，人名和产品名第一次出现时顺手交代一句是谁、是什么。
4. **“不是……而是……”全稿最多 2–3 处**，只留真正承担反转功能的那几处，其余换成别的句式。
5. 口语化，句子能直接念出来；不写书面腔，不写括号注释（TTS 会把括号里的内容也念出来）。
6. **数字按想要的读法写**：TTS 会把 3 位以上的阿拉伯数字当数值念（2019 → 两千零一十九）。年份、型号、编号写成汉字逐位（二零一九年），再在顶层 `"display": {"二零一九年": "2019 年"}` 里映射回去，字幕和 `at()` 看到的就是 2019 年；数量照常写（8 万星、41 颗星）。`qa_tts.py` 对漏网的数字给 WARN，`check_numbers.py` 用 Gemini 按实际读音听写核对（Whisper 会把读音统一写成阿拉伯数字，查不出来）。

## 开头（前 3 句，约 15 秒）

- 第一句就给出冲突或反常识的现象，不寒暄，不说“今天我们来聊聊”。
- 第三句前抛出问题，第四句前给出反直觉的答案或态度，用答案把人留下来。
- 范例：排行榜每周换第一 → 换模型只要改一行代码 → 那 AI 公司靠什么赢？ → “模型强不强，根本不是重点”。

## 主体

- 按“结论 → 拆解 → 证据或故事”推进，每个场景结尾都要给出往下看的理由。
- 文章里的框架（几根杠杆、三条路）最适合画成图，优先保留。
- 引语只保留最有力的一句，交代说话人是谁。

## 结尾的“收获”

- 落到一个观众带得走的东西：三个问题、一个判断标准、一个动作。
- 最后一句短、有力，最好能指回观众自己。

## 画面友好

- **画面里不编具体数字和名称**：画出来的账单、截图替身、文档里，金额、日期、版本号要么来自素材，要么用占位（¥ •••）；产品名、仓库名以当前一手来源为准（仓库改过名就用新名）。拿不准的照样画，但进 `to_confirm`。

- 每句话里要有一个能被画出来的名词或动作（排行榜、聊天框、漏斗、箭头反转）。
- 需要画面卡点的关键词要原样写在句子里，`at(sc, i, '关键词')` 才能找到它的时刻。
