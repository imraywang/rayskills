# 分镜套路库

按句子承担的叙事功能，选一个画面套路。代码范例在 `assets/template/scenes.example.js`，括号里是对应的函数名。

| 叙事功能 | 画面套路 | 范例 |
|---|---|---|
| 反常现象钩子 | 排行榜行位持续互换，周数计数器跳动；代码卡片里某个字段被替换 | `S.hook` |
| 抛出问题 | 大字问句弹出，轻微摇摆；下一句开始时上移、变淡 | `S.hook` |
| 否定一个常识 | 关键词大字 + 红叉逐笔画上 + 歪斜的红色结论 | `S.hook` |
| 名人金句 | 涂鸦头像 + 引号卡片 + 打字机逐字出现 + 关键词下划线 | `S.drucker` |
| 框架 / 清单（N 个要素） | 2×2 或 1×N 卡片，按旁白逐个画出：图标 + 关键词 + 小字说明 | `drawGrid` |
| 排除法 | 沿用同一套卡片：被排除的打叉、变暗，剩下的用椭圆圈住 | `S.cross` |
| 历史故事 | 产品界面草图 + 几张怀疑脸 + 一句反驳气泡 | `S.behavior` |
| 规律 / 时间线 | 竖排里程碑，灯泡 + 箭头逐个点亮，底部给出总结卡 | `S.behavior` |
| 抽象机制（多 → 一） | 散落的彩色小人被吸进漏斗，从底部弹出一个菱形“结论” | `S.breadth` |
| 结论公式 | 半透明遮罩盖住上一层，大卡片写“A ← 取决于 ← B” | `S.breadth` |
| 几条路径对比 | 顶部一个节点分出三支箭头，指向三个盒子；讲到哪条，哪条高亮，其余变暗 | `S.routes` |
| 东西被拿走 | 小人或数据图标沿路径移进别人的盒子 | `S.routes` |
| 循环 / 飞轮 | 两段旋转的弧形箭头 + 两侧标签 | `S.routes` |
| 因果反转 | 两个盒子沿弧线交换位置，箭头先消失再出现，标签从“你以为”变成“其实是” | `S.flip` |
| 收获清单 | 复选框逐个打勾；最后收缩上移，给结尾金句腾出位置 | `S.takeaway` |

## 节奏规则

- 一句话至少触发一个新视觉事件，说话时不能空着画面。
- 大元素提前 0.2–0.3 秒画出，关键词在开口那一刻弹出（`pop(t, at(...))`）。
- 场景内切换子画面时，旧元素 0.4 秒淡出，新元素同时淡入，不要硬切。
- 整片保持一个视觉母题。例如“四根杠杆”的网格在 levers 和 cross 两幕里沿用同一个位置，观众才看得出是同一个东西在变化。
