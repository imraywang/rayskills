# 风格参考卡

每期定风格时，挑一张参考卡，分镜表里写明「向谁靠、借什么」（`script.json` 顶层 `"style_ref": "<卡片 id>"`，`storyboard.py` 会打印出来）。参考卡是作者自己攒的，放在本机，不随 skill 分发：有 `local/style-refs.md` 就读它；没有就按下面的办法现建。

## 怎么建一张卡

1. 用户丢来一条想参考的视频链接，或者说「像某某那样」。
2. 抽帧：视频在用户浏览器里打开时用 `scripts/ref_frames.py`，均匀抽十来帧，存到用户的知识库或项目目录，不进本 skill。
3. 按帧写卡，只写抽帧核实过的东西，不凭印象：

   ```markdown
   ## <id> · <频道或作者名>

   - 来源：《片名》链接（发布时间，时长）。抽帧日期，帧数，分辨率。
   - **看到了什么**：版式、底色、字体、信息怎么组织、节奏。
   - **借**：打算学的两三点。
   - **不借**：不学的（它的配色、真人出镜方式等）。
   - **对应参数**：画幅、色板、主持人怎么放。
   ```

4. 借的是**版式、节奏、信息组织**，颜色一律换成作者自己的签名层（[ip-style.md](ip-style.md)）。

## 怎么用

- 参考卡一期只挑一张为主。
- 一种参考在成片上做出来、作者也认可之后，可以整理成固定风格反复用，并记进作者档案。
- 用户指定了参考就用指定的；没指定、也没有现成的卡时，按这期内容自己定版式，在分镜表里说明想法。
