# 签名层：每期都一样的那部分

视频分两层。**签名层**每期都一样，观众靠它认出「这是谁的视频」；**内容层**每期按内容自由设计（素材、构图、运镜），不受这里约束。

签名层由作者自己定，写在 [作者档案](../author-profile.md) 里。这份文件只说签名层包含什么、在工程里怎么接。

## 要定的四样

| 项 | 定什么 |
|---|---|
| 颜色 | 正文底、主字、次字，以及**一个**记号色。记号色只用来指重点，一镜最多指一处，用多了就不是重点了 |
| 签名时刻 | 开场和结尾那一幕怎么和正文区分（例如整屏换成记号色）。中间要不要再有一次，按内容定，最多一次 |
| 形象 | 有没有角落主持人，用哪个卡通形象。做法见 [host.md](host.md) |
| 声音 | 用哪个音色，见 [voice.md](voice.md) |

真实素材（截图、照片、录屏）保留原色，不去调色；它们周围的框、标签、高亮跟签名层的颜色走。

## 在工程里怎么接

```json
{
  "theme": "<色板名>",
  "host": { "avatar": "<形象名>", "big": [] },
  "voice": "<音色名>",
  "scenes": [
    { "id": "hook", "sig": true, "lines": ["…"] },
    { "id": "takeaway", "sig": true, "lines": ["…"] }
  ]
}
```

- `theme`：全片色板。底色、顶栏、字幕条和进度条一起用它。内置 `ray-ip`（浅底）和 `ray-ip-dark`（深底）两套，是本 skill 作者自己的配色；要用自己的颜色，在 `assets/hf-template/build.py` 的色板表里加一套，把名字写进档案。
- 某一幕写 `"sig": true`：这一幕是签名幕，`build.py` 会把顶栏换成签名配色；场景底色要在场景里自己换。
- `host` 的 `big` 留空：配音和校对之后跑一次 `host.py <project>`，生成角落口型，不花钱。不要主持人就去掉 `host`。
- 新项目模板已经写好 `theme`、`host` 和首幕 `sig`，按档案改成自己的；最后一幕的 `"sig": true` 自己加。
- 封面不在这里做，走 `ray-cover`。
