# Ray IP 规范 v0（2026-10-13）

视频分两层：**签名层**每期都一样，观众靠它认出「这是 Ray 的视频」；**内容层**每期按内容自由设计（画法、素材、构图、运镜），不受这份规范约束。这份规范只管签名层。

Ray 定下的方向：形象和声音统一；个性色是黑白灰，加一个记号色墨绿（取自形象的底色）；开场、结尾这几个签名时刻用整屏墨绿，正文白底。

## 颜色

| 用途 | 色值 |
|---|---|
| 正文底 | 暖白 `#F3F3F0`，卡片纯白 `#FFFFFF` |
| 主字 | 黑 `#111111`；次字和细线 灰 `#6E6E6E`；更浅的灰 `#8C8C8C` |
| 记号色 | 墨绿 `#054C4C`（形象底色，色相 180°） |
| 签名幕 | 墨绿底 `#054C4C`，卡片深绿 `#0D5F5E`，文字暖白 `#F3F3F0`，次字 `#9CC2BF` |

- 除此之外不用别的色相：没有橙、黄、蓝、紫。对、错这类语义也用墨绿和黑表达，灵感、提示用浅灰。
- 正文里墨绿是重点记号：一镜最多指一处（一个词、一个数字、一个色块）。用多了就不是重点了。
- 真实素材（截图、照片、录屏）保留原色，不去调色；它们周围的框、标签、高亮跟这套色。

## 签名时刻

- **开场**（片子第一幕）：整屏墨绿。钩子先上，第一句说完时形象从右下角升起，内容同时往左上收、让出角落。开头 3 秒留给内容抓人，形象不抢。
- **结尾**（最后一幕）：整屏墨绿。最后一句开口时形象出场，和收尾那一下（便利贴砸到清单上这类动作）一起落下，像签名。
- 中间要不要再有一个签名时刻（全片金句），按内容定，最多一次。

## 形象与声音

- 形象：`~/.config/ray-explainer/avatars/ray/base.png`，原版墨绿底贴纸卡通，底色正好是签名幕的墨绿，放上去融为一体。签名幕里静态出场，不花钱；要会说话的数字人主持人仍按 [host.md](host.md) 单独确认，项目有数字人时签名幕不再叠静态形象。
- 黑白版（白脸、黑衣、黑底高反差）留作白底上的备用，还没做成正式素材。
- 声音：复刻音色 `ray`（`"voice": "ray"`）。

## 字幕条、进度条、小标题

- 字幕条：黑底 `rgba(17,17,17,.88)`，暖白字。
- 进度条：正文黑色，签名幕里换成暖白。
- 小标题：灰。

## 在 ray-explainer 里怎么用

```json
{
  "theme": "ray-ip",
  "scenes": [
    { "id": "hook", "sig": true, "lines": ["…"] },
    …
    { "id": "takeaway", "sig": true, "pattern": "checklist", "lines": ["…"] }
  ]
}
```

- `"theme": "ray-ip"`：kit、套路、语法片段、字幕条和进度条一起换成这套颜色。
- 某一幕写 `"sig": true`：这一幕变成签名幕。第一幕的形象在第一句说完时出场，其余签名幕的形象在最后一句开口时出场。
- 改出场时刻：`"sig": {"avatar": {"at": {"line": 1, "phrase": "包括"}}}`；改位置大小：`{"avatar": {"x": 905, "y": 1545, "h": 500}}`（x 是形象中线，y 是底边）；不要形象：`{"avatar": false}`。
- 签名幕是语法片段时，片段换成签名色板，但内容不会自动让位，形象可能压住片段右下角：用 `render.js stills` 看一眼，必要时改 `avatar.at` 或 `x/y/h`。
- 旧项目自己目录里的 `kit.js`、`patterns.js`、`scenes.js` 里写死的颜色不跟这套走；要用 IP 规范重渲旧片，先换成模板里的新版 `kit.js`、`patterns.js`，`scenes.js` 里写死的色值逐个改。

## 还没覆盖的

- HyperFrames 专属风格模式（Ray 近几期大多走它）：签名层还没接进 `assets/hf-template/`，现在要手动照这份规范做开场和结尾。
- 封面：Ray 打算换掉现在的编辑版画封面，新封面可以照这份规范的颜色和形象来做。
- 片头 1 秒标识、声音 logo：还没设计。
