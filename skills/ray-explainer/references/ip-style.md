# Ray IP 规范 v0（2026-10-13）

视频分两层：**签名层**每期都一样，观众靠它认出「这是 Ray 的视频」；**内容层**每期按内容自由设计（画法、素材、构图、运镜），不受这份规范约束。这份规范只管签名层。

Ray 定下的方向：形象和声音统一（形象在左下角全片陪着，声音是复刻音色）；个性色是黑白灰，加一个记号色墨绿（取自形象的底色）；开场、结尾这几个签名时刻用整屏墨绿，正文白底。

## 颜色

| 用途 | 色值 |
|---|---|
| 正文底 | 暖白 `#F3F3F0`，卡片纯白 `#FFFFFF` |
| 主字 | 黑 `#111111`；次字和细线 灰 `#6E6E6E`；更浅的灰 `#8C8C8C` |
| 记号色 | 墨绿 `#054C4C`（形象底色，色相 180°） |
| 签名幕 | 墨绿底 `#054C4C`，卡片深绿 `#0D5F5E`，文字暖白 `#F3F3F0`，次字 `#9CC2BF` |

- 除此之外不用别的色相：没有橙、黄、蓝、紫。对、错这类语义也用墨绿和黑表达，灵感、提示用浅灰。
  - 例外：剪报风格（style-refs 的 `vk`，预定风格 id `jianbao`）的便利贴、纸片道具用牛皮纸 `#D9C29A`，印章用砖红 `#A8432F`，Ray 2026-10-23 同意；墨绿仍是唯一指重点的颜色。
- 正文里墨绿是重点记号：一镜最多指一处（一个词、一个数字、一个色块）。用多了就不是重点了。
- 真实素材（截图、照片、录屏）保留原色，不去调色；它们周围的框、标签、高亮跟这套色。

## 签名时刻

- **开场**（片子第一幕）和**结尾**（最后一幕）：整屏墨绿，卡片深绿、文字暖白。中间要不要再有一个签名时刻（全片金句），按内容定，最多一次。
- 签名幕只换底色和色板，不额外摆形象：形象一直在左下角（见下一节）。

## 形象与声音

- 形象：Ray 的扁平卡通形象（`~/.config/ray-explainer/avatars/ray/`），**全片缩在左下角**，嘴型跟着配音换、会眨眼，和 HyperFrames 那几期的做法一样（Ray 2026-10-13：「之前走 HyperFrames 的那种在左下角的方式就可以了」）。这一层不调视频模型、不花钱。
- 大机位（形象放大到画面中间、MiniMax H3 生成手势和表情）不是 IP 的一部分，要花钱，仍按 [host.md](host.md) 单独确认。
- 有了左下角主持人，字幕条上移到 y 1470，语法片段自动让出底部；kit 和套路的主画面别往 y 1440 以下放。
- 声音：复刻音色 `ray`（`"voice": "ray"`）。

## 横屏

横屏片（`"aspect": "landscape"`）的签名层和竖屏一样：颜色、签名幕、复刻音色都不变。不同处（Ray 2026-10-14）：形象换成只在关键句出现的小圆窗（卡片色底、墨绿细圈、不加投影，只露头肩），按主画面在左下 / 右下之间换，见 [host.md](host.md)「横屏」；不放进度条和小标题；字幕是白字黑描边、无底框。横封面走 `ray-cover` 的 `landscape`（16:9）。

## 深色版

`"theme": "ray-ip-dark"`：同一套 IP 放在深灰底上（参考差评君的深灰底 + 单一绿色），AI、科技题材的横屏片优先考虑。

| 用途 | 色值 |
|---|---|
| 底 / 卡片 | 深灰 `#1C1D1D` / `#2A2C2C` |
| 主字 / 次字 | 暖白 `#F3F3F0` / 灰 `#9A9A96` |
| 记号色 | 块面用提亮一档的墨绿 `#0B6B69`（`#054C4C` 在深灰上太暗，看不出来）；线条、高亮字用浅墨绿 `#9CC2BF` |
| 签名幕、主持人气泡 | 和浅色版一样，整屏墨绿 `#054C4C` |

规则不变：除了墨绿不用别的色相，墨绿一镜最多指一处。

## 字幕条、进度条、小标题

- 字幕条：黑底 `rgba(17,17,17,.88)`，暖白字。
- 进度条：正文黑色，签名幕里换成暖白。
- 小标题：灰。

## 在 ray-explainer 里怎么用

```json
{
  "theme": "ray-ip",
  "host": { "avatar": "ray", "big": [] },
  "voice": "ray",
  "scenes": [
    { "id": "hook", "sig": true, "lines": ["…"] },
    …
    { "id": "takeaway", "sig": true, "pattern": "checklist", "lines": ["…"] }
  ]
}
```

- `"theme": "ray-ip"`：kit、套路、语法片段、字幕条和进度条一起换成这套颜色。
- 某一幕写 `"sig": true`：这一幕变成签名幕（整屏墨绿）。
- `"host"` 的 `big` 留空：配音和 Whisper 校对之后跑一次 `host.py <project>`，生成左下角口型，不花钱。
- 新项目模板（`new_project.sh`）已经写好 `theme`、`host` 和首幕 `sig`；最后一幕的 `"sig": true` 自己加。
- 旧项目自己目录里的 `kit.js`、`patterns.js`、`scenes.js` 里写死的颜色不跟这套走；要用 IP 规范重渲旧片，先换成模板里的新版 `kit.js`、`patterns.js`，`scenes.js` 里写死的色值逐个改。
- 封面不在这里做：走 `ray-cover`，文章封面用 Punk 风格库、视频封面（默认只出 3:4、风格默认小Lin风A）用 Ray 真人照片，都按这套黑白灰 + 墨绿编提示词。

## 还没覆盖的

- HyperFrames 专属风格模式（Ray 近几期大多走它）：`script.json` 里 `sig: true` 的幕，`build.py` 自动把顶栏换成墨绿底暖白字；场景底色换墨绿 `#054C4C` 还要在场景里手动做。
- 片头 1 秒标识、声音 logo：还没设计。
- 形象的黑白版（白脸、黑衣、高反差）：试过，留作以后白底上的备用，还没做成素材。
