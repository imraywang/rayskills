# 风格 `guandian`：竖屏观点框架口播（框架梯子 + 打字文档卡 + 探头真人）

学的是两条海外竖屏短片：
- 一条讲「新奇感错觉」四步法，拆解在知识库 `50-系统/10-文档/观点框架口播包装拆解.md`。
- 一条讲「讲故事的五层阶梯」，动效主要照它做：镜头扎进梯子格、虚焦进场、扫光。

第一条成片是《同一个故事，你讲到了第几层》，2026-10-28 完成（v4），时长 95.8 秒。工程在 Ray 本机 `~/Movies/ray-explainer/2026-10-27-story-ladder-koubo/hf`。模板 `assets/styles/guandian/` 就是这个工程，去掉了这些东西：
- 真人素材、抠像、人声、配乐、字体文件
- 截图和封面：Ray 自己两条抖音的封面、CNBC 新闻截图、微软那期封面。每期自己取，放进 `assets/img/`

保留了四个 ffmpeg 合成的音效。整个工程由 `build.py` 一个文件生成，`index.html` 和 `compositions/` 都是它的产物，不要手改。

## 适合什么

- Ray 对着镜头录的「一套方法、几步框架、几层递进」观点口播，例如讲故事的五层、企业上 AI 的三条通道、普通人吃 AI 红利的四层。
- 每一步能举一个具体例子，最好一个例子贯穿全片（第一条成片用的是「微软给六万人发信」那条新闻，从第 1 层讲到第 5 层）。卡片可以接着上一张改，不用每次重画。
- 原片是横屏、固定机位，时长 1.5–2 分钟。要做成抖音、小红书、视频号用的竖屏 1080×1920。
- 和别的风格怎么分：
  - 「第一个……第二个……」项与项不相干的清单，用 `qingdan`。
  - 观点、科普口播，但没有清楚的步骤框架，用 `fenping`。

## 一眼看上去

| 版式 | 画面 | 用在哪 | 第一条成片 |
|---|---|---|---|
| **S** 分屏 | 奶油方格纸底：上面是演示区（标题 + 卡片），中间一次一个词的字幕，下面是探头真人 | 钩子、每一层的讲解、导流 | 钩子 11 秒；每层 9–16 秒 |
| **A** 全屏真人 | 全屏真人，白字带阴影，一次一个词，说到情绪词推近 8% | 每层讲完之后的那句定义或情绪句，给眼睛休息 | 每次 3–6.5 秒 |

- **框架梯子是全片的骨架。**
  - 钩子里第一次亮相：两根竖杆从下往上长出来，五格从下往上落位。说到「分成 5 层」时五格依次点亮，每格起光晕、扫一道光。
  - 每一层开头都回到这架梯子，点亮这一层，然后镜头扎进这一格。
  - 讲的时候左上角留一架小梯子，当进度条用。
  - 导流前五格全亮，背后炸开一圈放射光。
- **每一层一张文档卡，跟着口播打字。** 同一个例子在这一层的讲法逐字打出来。打字之外每层再加一个能「动」的东西：
  - 第 1 层：一张真实新闻截图。说到「划走了」，整张卡带着模糊甩上去。
  - 第 2 层：一道墨绿线划掉「裁员通知」，卡片抖几下。
  - 第 3 层：「签 / 不签」两个按钮弹出来。
  - 第 4 层：一条起伏曲线跟着口播一路画出来，峰顶落点、贴标签。
  - 第 5 层：判断句配墨绿底色块，旁边是那一期的真实封面，下面三个图标。
- **钩子要放真实数据。** 第一条成片放了 Ray 自己两条抖音：一条 1,103 播放，一条 130 万播放，数字 count-up。数据取自发布笔记里的 `douyin_views`。
- **探头真人和 qingdan 一样**：窗里放原片，窗上沿以上只放头部那一条的抠像，人的头顶越出窗框。
- 版式之间一律硬切，动的是画面里的元素和镜头。

## 视觉规范

**色板**：用 IP 色板（[ip-style.md](../ip-style.md)），全片浅底。

```
#f4f1ea 奶油底 + 48px 细方格纸纹（rgba(17,17,17,0.045)）
#ffffff 文档卡   #111 正文   #767676 次要字   #dcd8cf 没点亮的格子
#054c4c 墨绿：点亮的格子、光晕、划线、重点词、导流卡   #9cc2bf 浅墨绿：点亮格子的描边
```

参考片是黑底配深红；这里一律换成浅底配墨绿。深底上抠像会有一圈白边，所以不用深底（见「踩过的坑」）。

**字体**：
- 中文用思源黑体：Heavy 900 叫 `HeiHeavy`，Bold 700 叫 `HeiBold`。
- 层号（`1.`、`5`）用 Playfair Display Italic 900，墨绿。
- 文档卡的出处行用 JetBrains Mono。

**字号与位置**（演示区坐标，上半屏 1080×960）：
- 标题 64 HeiHeavy，top 74，居中。
- 梯子 400×620，在 left 340、top 190；每格 320×60，格距 118，标签 30 号「第 N 层 · 名字」。
- 小梯子 240×372，在 left 40、top 230。
- 文档卡 690×560，在 left 330、top 210，圆角 30，正文 40 号行高 1.5。
- 字幕 84 HeiHeavy 黑字，top 846；全屏真人字幕 76 白字，top 1330。

**画面里的字不和字幕重复**：层名在标题里、例句在文档卡里打出来的时候，`CHUNKS` 里那一段写成 `None`，不出字幕。

## 动效

这套风格比 qingdan 丝滑，靠的是下面这几样。换内容时保留，只改时间点。

- **镜头一直在动**：每个场景外面包一层 `.cam`，整场 `scale` 从 1 推到 1.045，`ease: none`。不要再在 `.cam` 上叠别的缩放，同一个属性两条 tween 会抢。
- **扎进格子**（`ladder_intro`）：
  1. 0 秒：梯子虚焦进场，从 0.9 放大到 1，0.55 秒。
  2. 0.08 秒起：标题逐字虚焦落下，间隔 0.045 秒。
  3. 0.28 秒：这一格 `back.out(2.6)` 弹一下，光晕亮起来。
  4. 0.5 秒：一道白光扫过这一格，0.6 秒。
  5. 1.25 秒：梯子以这一格为中心放大到 3.4 倍，同时模糊到 16px、淡出，0.5 秒，`power3.in`。
  6. 1.6 秒：文档卡从模糊里浮上来，从 1.14 缩到 1，0.7 秒，`expo.out`。小梯子从 1.25 缩回 1。
- **虚焦进场**（`blur_in`）：新元素都是从 `blur(18px)`、略大、透明，变成清楚，`expo.out`，0.4–0.7 秒。不用单纯的淡入。
- **甩出去**（`blur_out`）：退场带 14–18px 模糊往上甩，0.4 秒，`power3.in`。
- **打字**：每个字从下面 14px 浮上来，带 6px 模糊，0.22 秒，在口播那几个字的时间里按 stagger 铺开。`.ch` 要 `display: inline-block; white-space: pre`，否则模糊和空格都不生效。
- **字幕**：每个词从 1.18 倍、4px 模糊弹到位，0.14 秒。
- **光**：SVG 里每格背后一个 `feGaussianBlur` 的墨绿矩形当光晕，动 `opacity`；扫光是一条白色渐变矩形，用 `clipPath` 限在格子里，动 `attr.x`。SVG 子元素上不要用 CSS `filter: drop-shadow`，Chrome 渲不出来。
- **一次性高潮**：导流前梯子五格依次发光，背后放射线从 0.5 倍放大到 1，透明度 0.35，然后慢慢转 25°。全片只用这一次。

## 声音

- 人声：`prep.py` 调 `gate_breaths.py` 压吸气，时间轴不变。
- 配乐：`gen_bgm.py` 用 ACE-Step 本地生成，`script.json` 里有这期的 caption（极简电子，110 bpm，从头就有鼓，每段往上加一点，像爬楼梯）。出 3 条，响度归一到 −20 LUFS，`data-volume` 0.3。
- 音效：
  - 每层开头一个 `whoosh`（单独放 track 11），0.27 秒后格子弹起时一个 `click`。
  - 钩子「百万爆款」数字跑完、第 4 层「揭晓」、导流关键词用 `ding`。
  - 钩子「分成 5 层」用 `swell`。
- 出片后统一响度：`loudnorm=I=-16:TP=-1.5:LRA=11`。

## 做一条新片

1. **建工程**：
   ```
   mkdir -p <工程>/hf && cp -R $SK/assets/styles/guandian/. <工程>/hf/
   ```
   `$SK` 是 `~/.claude/skills/ray-explainer`。
2. **量脸**：从原片抽一帧，量鼻梁的 x 像素。
3. **准备素材**（抠像约 10 分钟，可以后台跑）：
   ```
   python3 prep.py <原片.mov> --face-x <像素> --end <秒>
   ```
   先加 `--dry-run` 看裁切。产出里多一张 `img/end_head.png`，是结尾垫在窗外的头部。
4. **取真实画面**，放进 `assets/img/`：
   - 钩子的两条对比数据：最好是 Ray 自己的作品封面和播放量。
   - 例子的出处：新闻截图、原帖截图（截法见 [qingdan.md](qingdan.md) 第 4 步：拦 cookie 弹窗，用 puppeteer 等数据加载完）。
   - 第 5 层（或最后一步）用 Ray 自己那一期的封面。
5. **改 `build.py`**：
   - `LEVELS`：框架每一层（步）的名字。层数不是 5 时，`ladder_svg` 的格距 `118` 和 `range(5)` 一起改。
   - `SEG`：镜头表，首尾相接。每层固定 S（讲解）+ A（定义或情绪句）交替。
   - `CHUNKS`：按顺序覆盖整条逐字稿，规则和 qingdan 一样（`None` 不出字幕；whisper 听错的写成 `(显示, 原文)`；`*词*` 标墨绿，每个镜头最多一处）。
   - `KEY`：每个场景里动作要对准的那个字的原片时间，从 `../words.json` 里查。
   - `PUSH`：全屏真人段在哪个词上推近。
   - `write_scenes` 里每层的文档卡内容。动效函数（`ladder_intro`、`blur_in`、`typing` 等）不要改。
6. **构建、检查**：
   ```
   python3 build.py
   npx --yes hyperframes@0.8.181 check --json
   npx --yes hyperframes@0.8.181 snapshot --describe false --at <每段一个时间点，再加每层开头 +1.5 秒那一帧>
   ```
   看拼图时检查：
   - 扎进格子那一帧（每层开头 +1.5 秒）梯子是不是放大虚化了。
   - 文档卡里打出来的字有没有被别的元素压住。
   - 探头的头顶是不是在窗外，最后一帧也要在。
7. **配乐**：`gen_bgm.py hf --dur <片长+6>`，挑一条，归一后转成 `assets/audio/bgm.m4a`。
8. **出片**：
   ```
   npx --yes hyperframes@0.8.181 render -q delivery -o ../raw.mp4
   ```
   然后用 loudnorm 统一响度，视频流直接复制。要给 Ray 手机看就再跑 `phone_export.py`。
9. **审片**：先跑 `qa_video.py --lufs -16`，再开 `review.py --tailnet`。

## 踩过的坑

- 抠像有白边时用浅底：深底上一圈白色描边很明显，奶油底上看不出来。第一条成片 v1 照参考片做的黑底，Ray 看了让整片改成浅色。
- 窗上沿以上的抠像层只留头部那一条（x 300–780）。v2 在 0:08 Ray 举手，手从窗框上面穿了出去。脸偏的素材按鼻梁位置挪 `#pop-out` 的 `left`，`prep.py` 里截 `end_head.png` 的 `crop` 也一起挪。
- 素材比成片早结束约 0.1 秒，窗外的抠像跟着没了，最后一帧头不在框外（v3）。现在结尾垫 `end_head.png`。
- 一开始的动效只有淡入加小位移，梯子缩到左边当进度条。Ray 说「没那么酷炫，也没那么丝滑」。v4 改成镜头推近、扎进格子、虚焦进场、扫光，才通过。
- 第 1 层的上滑箭头会压在打出来的字上，删了，「划走」只靠卡片甩上去表现。
- 钩子里 count-up 的数字用 `toLocaleString("en-US")` 加千分位，等宽字体，不会抖。
- 第 5 层判断句的墨绿底色要加在每个字（`.ch`）上，不能加在整个 `em` 上，否则字还没打出来，色块先出现了。
