## 适合什么

- 科普解说：公司、资本、时事、政策、人物，以及有大量新闻画面可以用的选题。Ray 2026-10-21 定：小Lin说的风格用来做科普视频。
- 横屏 1920×1080。配音用 Ray 的复刻音色（走 SKILL.md 的 ②③ 拿到配音和逐字时间）。
- 真人口播：第一条先略过了。以后 Ray 录了口播，口播段做法照她的：人居中，中景和近景跳切，每 2–4 秒切一次；讲图表时，人缩成左下或右下的圆形小窗。
- 数字人出镜（第二条起）：用 HeyGen 按句生成 Ray 的口型视频（做法见 [host.md](../host.md)「HeyGen」）。开场一句和两三句关键句全屏出镜；讲数字、对比的段落用 ali 式分屏：左边 x 110–1360 放内容，右边竖版人像卡（x 1440、y 300、360×480）里是同一段口型视频。人像卡里要露出肩膀以上：1920×1080 的源片缩到 1000×563 放进 350×470 的卡，`left:-325px; top:-12px`，不要把脸放大到占满卡片。
- 不适合纯教程、工具上手，那种用 `ali`。

## 一眼看上去

- **节奏**：新闻画面平均 2–3 秒切一次。画面上的字（标题、数字卡、章）停在原处，底下的素材在换。
- **底色**：深色带暗角。按 Ray 的 IP 用 `ray-ip-dark`（2026-10-25 起）：深灰 `#1C1D1D`、卡片 `#2A2C2C`、暖白字 `#F3F3F0`、灰字 `#9A9A96`，唯一的强调色是墨绿（块面 `#0B6B69`、线条和高亮字 `#9CC2BF`）。小Lin 原片的红、紫、金、深蓝都换掉：章节竖条、数字卡描边、高亮底都用墨绿。涨跌也不用红绿：涨用白色 ▲，跌用灰色 ▼，避免和墨绿撞色、也避免像投资建议。
- **画面来源**：真实新闻画面占一半以上，右上角标「来源 · 日期」。
- **左上角**：常驻一个章节标签（墨绿竖条加章节名）。
- **画板不静止**：每块画板的内容包在 `.drift` 里，整段时间缓慢推近 4%。新闻画面本身也在缓慢推近。这只是打底，检查把它算作没变化；成片检查列出「3 秒以上没有明显变化」的段落，要在讲到那一处时补真正的动作（纸面推近、高亮、数字滚动、聚光）。
- **字幕**：白色粗黑体，加半透明黑底（`rgba(0,0,0,.55)`、圆角 8，Ray 2026-10-25 定），按标点断句。所有画面上都有字幕。同一时刻只出一条：`build.py` 断句后把每条的结束时间截到下一条开始，否则换句处会两条叠在一起。

## 时间怎么对

`build.py` 读配音的 `timeline.json`（每个字的开口时间）。模板里写 `@[场景.第几句.短语±秒]`，构建时换成那个短语开口的秒数；`data-until="@[...]"` 换成持续时间。镜头表 `SHOTS`、章节表 `CHAPTERS` 用同一种写法；字幕按标点自动断句。改稿重配音以后，重跑 `build.py` 就全部对齐，不用手调时间。

## 做一条新片

1. **配音**：照 SKILL.md 的 ① 到 ③ 走完，拿到 `timeline.json` 和 `narration.m4a`（项目画幅用 `--landscape`）。
2. **建工程**：`cp -R $SK/assets/styles/xiaolin <工程目录>`。把 `timeline.json` 放进 `src/`，配音和配乐放进 `assets/audio/`，再把 `gsap.min.js` 放进 `assets/`。
3. **找新闻画面**：按每幕要讲的事搜 YouTube（`yt-dlp "ytsearch5:<关键词>"`），用 `--download-sections` 只下需要的那几十秒，放进 `raw/`。挑画面时先拼缩略图看一遍，带水印的不用。在 `cut.sh` 里写好每个镜头（名字、源文件、起点、时长、模式），裁成 1920×1080 静音片段：
   - 竖屏素材用 `blur`。
   - 美联社素材要挡台标，用 `crop-ap`。
   - 底部压着字幕或标题条、角上有台标的，用 `sub`（放大 1.22 倍）；还挡不住用 `deep`（1.35 倍）；字幕很高、横幅很大的用 `tight`（只留中间 58%）。
   - 片头 1 秒常是别的镜头，先看缩略图再定起点。
   - CCTV+ / 央视新闻的片子开头约 3 秒有动画台标，结尾约 6 秒是台标卡，都要避开。
   - 每裁完一批，把所有镜头各抽一帧拼成缩略图看一遍：第二条有十几个镜头第一次都挑错了时刻（采访而不是现场、订阅提示卡、YouTuber 本人、模型沙盘），全靠这一步发现。
   - 素材多的片子（第二条 55 个镜头），可以分三个子代理并行找：前半片的新闻画面、后半片的新闻画面、公司 logo / 照片 / 文件截图 / 股价数据。每个子代理只写自己的目录，最后交一份 `manifest.md`（文件、来源网址、发布方、日期、好用的时间段、台标和字幕位置、分辨率）。
   - 公司 logo：维基共享资源、svgl、LobeHub 图标库（国产 AI 品牌大多在这里），每个做一份透明底原色版和一份暖白单色版（深色底用白版）。
4. **生成素材**：
   - `python3 make_bg.py` 生成底图。
   - 改 `make_stamps.py` 的 `STAMPS` 表，再跑一遍生成盖章图片。
   - 需要人身后大字的镜头，跑 `remove-background` 生成抠图。
   - 引语卡的背景照片用 ffmpeg `boxblur` 预先虚化。
5. **改 `src/template.html`**：
   - 每一幕的画板（`.board`）放在 track 3，叠在新闻画面上的字和卡片放在 track 4。
   - 动画写在脚本里，用 `pop` / `rise` / `big` / `pie` / `trace` / `titleIn` 几个函数，时间点都写成 `@[...]`。
   - 连线和箭头不要直接出现，要从起点长到终点（`scaleX` / `scaleY` 从 0 到 1，`transform-origin` 放在起点一侧）；箭头要一直指到目标框上。
   - 叠在画面上的大字不要和同时出现的字幕重复（第一条审片：「最后流向了哪里」大字和字幕一模一样）。
6. **构建**：
   ```
   python3 build.py
   bash make_fonts.sh
   npx hyperframes lint
   python3 $SK/scripts/check_clip_slots.py index.html
   ```
   lint 要 0 error；`check_clip_slots.py` 列出比自己在画面上停留时间短的视频片段——片段先播完就定格，看起来是卡顿（第二条 1:20 那处卡顿就是这样，五个镜头短了 0.2–1.3 秒），要重新裁长一点或换镜头。
7. **静帧检查**：`snapshot --describe false`，每段截 1 帧，着重看这几点：
   - 纸面有没有推近到要讲的那句。
   - 大字压在亮画面上看不看得清。
   - 字幕有没有压在白纸上。
   - 带问号、逗号的大字有没有视觉居中：全角「？」「，」占一个字宽，整行看起来偏左。把结尾标点放进 `<em>` 绝对定位挂在行外，居中只按文字算（`.pw em { position:absolute; left:100% }`）。
8. **出片**：`render -q looks`。配音响度沿用 −21 LUFS。配乐默认用 ElevenLabs Music 按章节生成（见 [hyperframes.md](../hyperframes.md)「配乐」），音量 0.10，比人声低 12 dB 左右；第一条用本地配乐时是 0.22。另出一份 720p 手机版。

渲染之后：先跑 `qa_video.py`（ali 用 `--lufs -14`，xiaolin 用默认的 −21），看切点图；然后开 `review.py --tailnet`，把手机地址发给 Ray，按他写在画面上的批注改。

## 踩过的坑

- **黑帧风险**：lint 警告「heavy overlay」——带 `filter:blur`、`radial-gradient`、`clip-path` 的元素接近 40 个时，渲染出来前半段会是黑帧。所以：
  - 暗角、木桌底图用 PNG。
  - 虚化背景预先用 ffmpeg 做好。
  - 气泡只用 linear-gradient。
  - 标题出场用 scale 加 opacity，不用 blur。
- 不能对 `letterSpacing` 做动画（lint 报 error），改用 scale。
- 带时间的 `<video>` 不能嵌在带时间的元素里。手机框里的录屏、人像抠图都放在根下，靠定位叠上去；不带时间的 `<video>` 不会播放，静态背景用图片。
- 竖屏素材、带台标的素材在 `cut.sh` 里处理，不在 CSS 里裁。
- 纸面推近的坐标按 `.paper` 的左上角 (323, −285) 算，`PS()` 已经写好，传页面像素坐标就行。
- **叠放顺序看 DOM 先后，不看 `data-track-index`**：第二条把「产业链」大字放在 track 11、抠图在 track 10，字还是在人后面；把字的 div 挪到抠图 `<video>` 后面才到前面来。
- 人身后的大字放三个字时，中间那个字一定被头挡住。Ray 两次都要改：要么只放在头两侧，要么干脆放在人前面（第二条最后定为放在人前面）。
- 数据要带进页面时（股价点、累计长度），写成 SVG 的 `data-*` 属性，脚本里 `JSON.parse` 读出来；GSAP 的 `onUpdate` 在逐帧渲染时也会触发，画线、移动圆点都是确定的。
