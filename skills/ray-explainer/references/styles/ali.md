# 风格 `ali`：真人口播打底 + 米白画板页

学的是 Ali Abdaal 2026-10 的两期视频：
- https://www.youtube.com/watch?v=szVXpM7VVMg
- https://www.youtube.com/watch?v=BNRfzI6E1Es

拆解笔记在 Ray 知识库的 `10-创作/40-课程/零基础用AI做视频/参考-Ali Abdaal剪辑拆解.md`。

第一条成片是《零基础 AI 做视频》第 1 节 v4（2026-10-21，3 分 10 秒），工程在 Ray 本机 `~/Movies/ai-video-course/l01-v4`。模板 `assets/styles/ali/` 就是这个工程，去掉了素材文件。

## 适合什么

- Ray 对着镜头录了一整段口播（横屏、固定机位），要剪成课程或长视频：口播打底，中间穿插全屏画板页、真实截图和录屏。
- 横屏 1920×1080。竖屏没做过，要做得先改版位。
- 不适合纯配音的解说片，那种走 SKILL.md 主链路或专属风格模式。

## 一眼看上去

- **口播页**：Ray 居中，镜头缓慢推近。左侧下三分之一出白卡，卡上是深色粗黑字，强调词用深珊瑚色，逐词出现。列举用白色胶囊横排，否定项前面是红色 ✕，肯定项是绿色 ✓。
- **画板页**：米白底，加一道浅色大弧形做纵深。内容放在左边和中间（x 110–1360）。Ray 固定在右侧竖版人像卡里，和口播同步。
- **转场**：口播和画板之间全部硬切，不做滑动、缩放这类转场。动的只有画面里的元素：淡入、略微上移、去模糊。
- **开场标题字放在人身后**：用人像抠图分层，字被头挡住一部分。

## 视觉规范

**色板**：不用 IP 色板，用房间的颜色。Ray 的房间是米白墙、橙色台灯，Ray 2026-10-20 定的。换了录制环境要重新取色，只改 `:root` 里的变量。

```
--paper #f6f1ea  底色        --swoosh #ece4d8  弧形色块     --card #fff  卡片
--ink #2b2622    正文/标题   --soft #7a6f66    次要字       --line #e6ddd1  路径底线
--coral #e0754b  强调        --coral-deep #b9552f  白卡上的强调字   --coral-tint #fbe6dc  浅强调底
--ok #4f8a5b / --no #c8553d  ✓ ✕ 图标
阴影：0 18px 48px rgba(70,48,30,.10), 0 2px 6px rgba(70,48,30,.06)
```

**字体**：只用思源黑体。标题用 Bold 700（`Head`），正文用 Medium 500（`Sans`）。衬线体（思源宋体）试过，Ray 不要。按全片用到的字裁成 woff2，每个约 60 KB，见下面的 `make_fonts.sh`。

**字号**：
- 画板标题 58，副标题 30（`--soft`）。
- 口播白卡 50–68。
- 胶囊 28–38。
- 字幕 40。
- 人身后的大字 380。

**卡片**：白卡，不加描边。圆角 20–26，用上面那组柔投影。不用硬投影，不用黑色粗描边。

**人像卡**（`#pcard`）：
- 位置 x 1440、y 300，大小 360×480，5px 白边，圆角 26。
- 里面是一个全长 `aroll.mp4` 的静音视频，`data-start=0`、`data-media-start=0`，所以全片都和口播同步。
- 画板页出现时淡入，回到口播时隐藏。由 `build.py` 的 `BOARDS` 生成，相邻的画板页合并成一段。
- 裁切 `left:-355px; top:-78px; width:1150px` 是按 Ray 的脸在画面 47%、43% 处算的。换了机位要重算，让脸落在卡片中间。

**字幕**（`build.py` 生成）：
- 画板页（`cap-b`）：灰字，不加底。
- 口播页（`cap-a`）：白字，加半透明深色底 `rgba(28,22,18,.52)`。
- 屏幕上已经有同一句大字时，把那句字幕的开始时间写进 `HIDE`，不显示。
- 字幕不给关键词上色。

**人身后的字**：
- 把那几秒的口播裁出来，`npx hyperframes remove-background seg.mp4 -o assets/matte.webm`，生成透明背景的人像 WebM。
- 叠放顺序：口播 → 字 → 抠图，三层都放在 `#cam .inner` 里，跟着机位一起动。
- 每个字单独定位：先在抠图上量出头的左右边界（Ray 的头大约在 x 690–1060），字放在头的两侧，不要被挡住关键的那个字。
- 字用浅色 `#fffaf3`，加柔阴影。
- 抠图片段和原片可能差几帧，用 `data-media-start` 微调，第 1 节是 0.34。截两帧对齐看边缘。

**节点路径**（`data-path` + `buildPath` / `lightNode`）：
- 讲流程、步骤、路线图都用它：一条底线，加一条珊瑚色的填充线。
- 讲到哪一步，那一步的节点变成实心，同时放一圈扩散的波纹。
- 节点标签是白色胶囊，放在线上方或下方。
- 一期里反复用同一种路径，起到章节进度条的作用。

**截图窗口**（`.win` + `focus` / `ringAt`）：
- 白色窗口，带三个小圆点标题栏，里面放 2560 宽的原始截图。
- 用 `focus(img, 视口宽, 视口高, 区域, 填充比, 时间, 时长)` 推到要讲的那块。
- 再用 `ringAt` 画珊瑚色圆角框圈出来，周围压一层很淡的暗。
- 截图上的区域坐标按原图像素量。

## 动效

- **逐词出现**：所有带 `data-t` 的 `.w` 都按这组参数出现：`{opacity:0, y:10, blur(8px)} → {1, 0, blur(0)}`，0.38 秒，`power2.out`。`data-t` 取 whisper 词级时间，比说出来早 0–0.1 秒。
- **`rise`**：上移 16px 淡入，0.45 秒。**`pop`**：上移 12px、缩放 0.96 到 1，0.4 秒，`power3.out`。不用回弹（`back.out`），也不用砸章。
- **机位**：用 `build.py` 的 `CAM` 表。
  - 常态：人居中，`scale 1`，按段缓慢推到 1.03–1.05。
  - 强调推近：`scale 1.2`、`y 100`，每 3 分钟 2–3 处，放在情绪句上。
  - 人不偏到一侧。人放大偏到一边那种构图 Ray 不要。

## 声音

- 人声：先用 `scripts/gate_breaths.py` 去掉句间吸气音，A-roll 视频静音，声音走 `<audio id="voice">`。
- 配乐 0.11。
- 音效只用很轻的 pop，音量 0.16，用在卡片、胶囊、节点出现的时候。whoosh、砸章、打字声都不加。
- 出片后统一响度：`loudnorm=I=-14:TP=-1.5:LRA=11`，视频流直接复制。

## 做一条新片

1. **建工程**：`cp -R $SK/assets/styles/ali <工程目录>`，把素材放进 `assets/`：
   - `aroll.mp4`：口播，按 1920×1080 或更高。
   - `voice.wav`：去吸气音后的人声。
   - `bgm.mp3`。
   - `gsap.min.js`。
   - `sfx/pop.wav`。
   - 截图、录屏。
2. **转写**：`mlx_whisper <wav> --model mlx-community/whisper-large-v3-turbo --language zh --word-timestamps True`。按口播实际内容校对错字，写进 `build.py` 的 `CAPS`，格式是 `(开始, 结束, 文本)`。
3. **分段**：按句子决定每段是口播还是画板，画板页的时间段写进 `BOARDS`。经验比例是口播约 45%、画板约 55%，单个画板页 5–20 秒。
4. **改 `src/template.html`**：
   - 每个画板页是一个 `<section class="clip board" data-track-index="3">`。
   - 口播页上的卡片放在 track 5；同一时刻要出现第二张卡片时放 track 11。
   - 动效写在脚本里对应场景的注释下面，模板里每个组件都有用法。
5. **构建**：
   ```
   python3 build.py
   bash make_fonts.sh <思源黑体 OTF 目录>
   npx hyperframes lint
   ```
   lint 要 0 error。warning 里「section 应拆成子合成」「轨道太密」可以不管。
6. **静帧检查**：`npx hyperframes snapshot --describe false --at <每段一个时间点> -o snaps`，看拼图，至少检查这几点：
   - 卡片是否压到脸。
   - 卡片里的空格有没有丢。
   - 截图窗口里推近的位置对不对。
   - 有没有重复的字幕。

   `--describe false` 不能省，否则会把帧发给外部模型。
7. **出片**：
   ```
   npx hyperframes render -q looks -o raw.mp4
   ```
   然后用 ffmpeg 统一响度，再出一份 720p、crf 30 的手机预览（30 MB 以内，方便直接发给 Ray）。

## 踩过的坑

- `<video data-start>` 不能放在带时间的元素里面，lint 会报 `video_nested_in_timed_element`。人像卡、手机里的视频都放在根下，再用定位叠到画板上面。DOM 顺序要放在画板 section 后面，不然会被画板盖住。
- 同一条轨道上时间重叠的两个元素会冲突，口播页的第二张卡片放 track 11。
- CSS 里写了 `transform` 的元素，再用 GSAP 动 x、y 会冲突（`gsap_css_transform_conflict`）。旋转改用 `tl.set(el, {rotation})`。位置动画用 x、y，不用 left、top。
- 工程根目录只能有一个 html，模板和备份都放进 `src/`。
- `.w` 是 inline-block，开头和结尾的空格会被吞掉，所以要加 `white-space: pre`，模板已经加了。
- 在 Studio 里打开过以后，`src/template.html` 会被加上 `data-hf-id` 属性。用正则改模板时要能容忍这些属性。
- 字体子集按 `index.html` 里实际出现的字生成，改了文案要重新跑 `make_fonts.sh`，否则新字会显示成系统字体。
