# 风格 `qingdan`：竖屏清单口播（编号卡 + 奶油三层卡 + 探头真人）

学的是 Brock Mesarich 的 YouTube Shorts《5 个 GitHub 仓库》，https://www.youtube.com/shorts/rxOcBowQcS0 。拆解在知识库 `50-系统/10-文档/清单口播包装拆解.md`。

第一条成片是《我每天离不开的四个生产力工具》，2026-10-27 完成，时长 81.6 秒。工程在 Ray 本机 `~/Movies/ray-explainer/2026-10-27-four-tools-koubo/hf`。模板 `assets/styles/qingdan/` 就是这个工程，去掉了这些东西：
- 真人素材、抠像、人声、配乐
- 截图和工具 logo（第三方商标，每期自己取）

保留了四个 ffmpeg 合成的音效。整个工程由 `build.py` 一个文件生成，`index.html` 和 `compositions/` 都是它的产物，不要手改。

## 适合什么

- Ray 对着镜头录的「第一个……第二个……」清单口播，例如工具、仓库、书、方法。原片是横屏、固定机位，时长 1–2 分钟。要做成抖音、小红书、视频号用的竖屏 1080×1920。
- 每一项都拿得出真实画面：官网、GitHub 页、自己的软件界面、手机录屏。
- 不适合的情况：
  - 观点口播、科普口播，需要示意动画讲原理的，走 `fenping`。
  - 横屏课程片走 `ali`。

## 一眼看上去

六种版式，镜头表里每段选一种：

| 版式 | 画面 | 用在哪 | 第一条成片的时长 |
|---|---|---|---|
| **H** 钩子 | 奶油底：上面是大字加数字 count-up，下面是探头真人 | 开头 5–8 秒：「每天离不开的 4 个」→ 四个 logo 弹出 → 账号成绩数字 | 7.6 秒 |
| **N** 编号卡 | 全屏真人，胸口一个巨大的描边 `#1`，项目名用英文衬线斜体逐个字母出现 | 每项开头「第 N 个，名字」，硬切进来，配 whoosh | 每个 1.3–2.2 秒 |
| **P** 三层卡 | 奶油底：上层真实截图卡，中层一次一个词的字幕，下层探头真人 | 每项的说明，可以在中途换第二张卡 | 每个 11–15 秒 |
| **R** 串线 | 奶油底：几个 logo 连成一条线，每说一个字落一个关键词 | 收尾时把几项串起来 | 7.5 秒 |
| **F** 全屏真人 | 全屏真人，白字带阴影，一次一个词，说到关键词时推近 | 结尾判断句，给节奏喘口气 | 5 秒 |
| **C** 导流 | 奶油底：墨绿卡「评论区打」，下面一个大关键词 | 最后 3–4 秒 | 4.2 秒 |

- **探头真人是这套包装最有辨识度的地方。**
  - 下方是一个圆角窗（x 60–1020，y 1210 起），窗里放原片。
  - 窗上沿以上只放抠像，所以人的头顶会越出窗框。
  - 窗和抠像用的是同一条 `face_pop` 素材、同样的位置，只是裁剪区域不同。
- 版式之间一律硬切，动的只有画面里的元素。
- 截图卡上方有一行灰色等宽字，标出处（`obsidian.md`、`github.com/...`）。

## 视觉规范

**色板**：用 IP 色板（[ip-style.md](../ip-style.md)）。

```
#f4f1ea 奶油底（右上角一团白光，左边一团暖灰）
#111 正文、截图卡底   #767676 次要字（再浅就不过对比度检查）
#054c4c 墨绿：编号描边、导流卡、字幕重点词   #9cc2bf 浅墨绿：编号渐变、深底上的强调
```

**字体**：
- 中文用思源黑体：Heavy 900 叫 `HeiHeavy`，Bold 700 叫 `HeiBold`。
- 编号、项目名、英文点缀用 Playfair Display Italic 900（HyperFrames 自带）。
- 终端卡用 JetBrains Mono。

**字号**：
- 编号 `#N` 用 440，项目名用 86–104。
- 钩子大数字 200–250。
- 三层卡字幕用 84 HeiHeavy 黑字，top 846。
- 全屏字幕用 76 白字，top 1330。

**画面里的字不和字幕重复**（沿用 fenping 的规矩）：
- H、N、R、C 段不出字幕，由画面上的字承担。
- P、F 段才出逐词字幕。
- 截图卡里只放真实界面和出处，不加中文说明。

**安全区**：
- 截图卡在 y 150–750。
- 字幕带在 y 846–950。
- 探头的头顶大约在 y 1050。
- 编号卡的数字和名字放在 y 1150–1610，压在衣服上，不挡脸，也不碰底部的话筒。

## 动效

- 截图卡进场：淡入，上移 60，从 0.94 放大到 1，0.42 秒，`power3.out`。停住后慢慢推近到 1.06，`ease: none`。换卡时旧卡上移淡出 0.25 秒，新卡接着进。
- 编号卡：数字从 1.18 缩到 1，0.28 秒；名字晚 0.2 秒，逐个字母上移 26，间隔 0.03 秒。
- 每个动作对准说到那个词的时间。场景内用相对时间，原片时间写在注释里。
- 抠像不要做位移或缩放；要推近的话，窗和抠像必须放在同一个外层里一起动。

## 声音

- 人声：`prep.py` 调 `gate_breaths.py` 压吸气，时间轴不变。
- 配乐：`gen_bgm.py` 用 ACE-Step 本地生成，`script.json` 里有这期的 caption（轻快的 lo-fi pop，104 bpm，从头就有鼓）。出 3 条，响度归一到 −20 LUFS，`data-volume` 0.3。第一条成片选了响度最平稳的 `bgm_23`，Ray 没有逐条试听。
- 音效：
  - 每个编号卡前 0.12 秒一个 `whoosh`（放在单独的 track 11，免得和别的音效重叠）。
  - 钩子数字、导流关键词用 `ding`。
  - logo 弹出、串线落字用 `click`。
- 出片后统一响度：`loudnorm=I=-16:TP=-1.5:LRA=11`。

## 做一条新片

1. **建工程**：
   ```
   mkdir -p <工程>/hf && cp -R $SK/assets/styles/qingdan/. <工程>/hf/
   ```
   `$SK` 是 `~/.claude/skills/ray-explainer`。
2. **量脸**：从原片抽一帧，量鼻梁的 x 像素。
3. **准备素材**（抠像约 10 分钟，可以后台跑）：
   ```
   python3 prep.py <原片.mov> --face-x <像素> --end <秒> --names "这期的英文名"
   ```
   - 先加 `--dry-run` 看裁切。
   - 背景要和人分得开，否则抠像边缘会脏。浅色墙、深色头发效果最好。
4. **取截图**：每项 1–2 张真实画面，放进 `assets/img/`。
   - 官网和 GitHub 用 2× 截图，1280×800 视口。
   - 网站有 cookie 弹窗时，拦掉弹窗脚本再截（Tailscale 的是 Ketch，挡在 shadow DOM 里，删节点没用）。
   - 本机工作台要等数据加载完再截。headless Chrome 的 `--virtual-time-budget` 等不到接口返回，改用 puppeteer 等「正在整理」消失。
   - 工具 logo 取官网的 apple-touch-icon 或 favicon.svg。
5. **改 `build.py`**：
   - `SEG` 是镜头表，首尾相接。
   - `NUMS` 是每项的编号和名字。
   - `CHUNKS` 按顺序覆盖整条逐字稿：
     - 显示为 `None` 的段不出字幕。
     - whisper 听错的写成 `(显示, whisper 原文)`。
     - `*词*` 标墨绿，每个镜头最多一处。
     - 构建时打印「切在一个 whisper 词中间」的地方，要把相邻两块合并或者重切。
   - `write_scenes` 里每个场景的卡片和时间点照这期内容改。`vault_tree`、`git_log`、`code_card` 是第一条成片的真实内容，换成这期的。
6. **构建、检查**：
   ```
   python3 build.py
   npx --yes hyperframes@0.8.181 check --json
   npx --yes hyperframes@0.8.181 snapshot --describe false --at <每段一个时间点>
   ```
   - 窗和抠像的 `container_overflow`、`escaped_container` 是故意裁的，可以忽略。
   - 编号卡数字和名字的重叠已经标了 `data-layout-allow-overlap`。
   - 看拼图时检查：探头的头顶是不是在窗外，钩子的数字有没有换行，截图有没有弹窗或灰色遮罩。
7. **配乐**：`gen_bgm.py hf --dur <片长+6>`，挑一条，归一后转成 `assets/audio/bgm.m4a`。
8. **出片**：
   ```
   npx --yes hyperframes@0.8.181 render -q delivery -o ../raw.mp4
   ```
   然后用 loudnorm 统一响度，视频流直接复制。成片超过 30 MB 发不到手机，要给 Ray 手机看就再跑 `phone_export.py`。
9. **审片**：先跑 `qa_video.py --lufs -16`，再开 `review.py --tailnet`。

## 踩过的坑

- 钩子数字里的 `<span>` 被 `.stat span { display: block }` 一起选中，“100+”和“近 5 万”被拆成好几行。标签要用单独的 class。
- 手机截图里的工作台是 Ray 的真实数据，带「当前关注」，公开前要让 Ray 确认。
- 抠像用的是 `face_pop`，不是全屏素材。全屏素材太紧，探头窗里的人会太大。
