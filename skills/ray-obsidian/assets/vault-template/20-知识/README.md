# 长期知识库

这里保存能够跨文章、跨项目复用的概念、对象、问题、观点、案例、方法和主题地图，不保存整篇原始资料。

- `10-概念/`：概念和解释框架
- `20-人物与组织/`：人物、组织和公司
- `25-产品与模型/`：产品和模型
- `30-问题/`：尚未收敛、值得反复追问的问题
- `40-观点/`：作者愿意承担的判断
- `50-案例/`：可以重复引用的案例
- `60-方法/`：可以执行的方法和方案
- `70-知识地图/`：连接多个知识单元的主题入口

分类以每篇笔记的 `kind` 为准，目录只用于浏览。每篇非地图知识都应能追溯到仍然存在的本地来源或原始链接。
