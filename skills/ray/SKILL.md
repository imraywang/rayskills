# ray：总入口

用户不用记每个 skill 的名字，把真实处境丢过来，这里判断此刻最该做的一步，交给对的成员 skill。这里只做路由和阶段衔接，怎么写、怎么画、怎么验收，都以成员 skill 自己的 SKILL.md 为准，不在这里临时改它们的规则。

## 怎么判断

1. 读当前对话里已有的信息：处境、目标、材料、卡在哪。
2. 对照路由表选**一个** skill，用一句话说明为什么是它，然后照它的 SKILL.md 做。请求里顺带提到几件事时，选此刻最该做的那一步，其余列为下一步。
3. 信息不够判断时，只问一个最关键的问题。
4. 用户已经给了明确终点（“把这个 idea 做成文章、出封面、存进 X 草稿箱”），就不再一步一停：读 [content-pipeline.md](references/content-pipeline.md)，按阶段连续执行。正常的阶段交接、验证和可恢复的重试不打断用户。

连续执行的终点固定是**验证过的草稿**。公开发布不在任何一条链路里，也不能从“推送”“发布流程”或以前的许可里推出来。

## 平台动作先分级

交给 `ray-wechat` 或 `ray-x-article` 之前，先只看用户**当前这轮的原话**，选一级。两个平台 skill 用的是同一套，不各自解释：

| 级别 | 能做什么 | 什么时候是这一级 |
|---|---|---|
| `local_only` | 只做本地产物：排版、预览、封面、交付包，不碰线上后台 | “先看看”“给我预览”“准备交付包”，或整句没说落到哪个平台的哪里 |
| `draft_write` | 创建或更新平台草稿，并完整回读 | 原话里同时有平台和落点：“保存到微信草稿箱”“更新 X Article 草稿”“放进 X 后台” |
| 公开发布 | 不做 | 这套判定永远到不了这一级，要另开明确的发布任务，逐个平台确认 |

三种容易判错的说法：

1. **点了平台、动词含糊**（“推送到 X”“推送到微信”“同步到两个平台”“上架后台”）：先把本地产物做完，再问一句“本地已经好了，要现在写进〈平台〉草稿箱吗？”，得到肯定答复才写。不擅自写，也不做完就不吭声。
2. **没说平台落点**（“过稿 OK”“进入下一阶段”“走完整发布流程”）：按 `local_only`，不问也不写。
3. **说了“发布”“群发”“公开”**：仍然只做到草稿，并说明公开发布不在这条链路里。

授权不跨轮、不跨平台：以前任务里的许可、对另一个平台的许可、已有的草稿 ID、已经登录、白名单刚修好，都不算这一轮的授权。修好登录、出口 IP 或文件共享，只是让原任务能继续，不会把级别抬高。拿不准就按 `local_only`。

## 工作台任务队列

装了知识工作台（ray-dashboard，随 [rays-brain-kit](https://github.com/imraywang/rays-brain-kit) 安装，不在本仓库）的知识库里，用户排队的协作请求会写在 `50-系统/40-自动化/AI任务队列.md`：frontmatter 是 `kind: ai-task-queue`，「## 待处理」下每行 `- [ ] 时间 · 动作 · [[目标笔记]]`。读上下文时顺手看一眼；文件不存在或没有未勾选的，就不提它。

- **有待处理项，用户这一轮也没给别的任务**：把队列摆出来，用户确认后再认领。「起草」按目标写作任务的成稿包交给 `ray-writer`。
- **用户这一轮有明确任务**：先办这一轮的事，收尾时提一句队列里还有几条。
- **每办完一条**：把那行勾成 `- [x]`，行尾补上产物链接，工作台和下一个会话才看得到去向。
- 队列里的动作都只做到本地产物。认领队列不算平台写入授权，平台动作照上面分级。

## 常见衔接

上一步出了结果之后通常接哪一步。这是经验，不是固定流水线：

- **没有兼容的知识库，但想长期积累**：先 `ray-obsidian` 建好，再把根目录和材料交给 `ray-writer`。
- **长文写完并通过检查**：接 `ray-cover` 出封面；要进公众号接 `ray-wechat`，要进 X 接 `ray-x-article`，两者都只存草稿。
- **一个判断已经能在一条视频里讲清**：`ray-kb` 的快速口播，只建一份母稿，不强制先补候选卡、写作任务或长文。
- **长文要再分发成口播**：`ray-kb` 出绑定母稿指纹的口播稿；要做成解说视频再接 `ray-explainer`。
- **动笔前想知道一个话题最近怎么被讨论**：装了 `ray-trend-search` 就先调研，把带日期和证据的结论交给 `ray-writer` 或 `ray-kb`。
- **内容主体是别人的文章**：`ray-writer` 的译介。`source_permission` 没放行时，后面的平台 skill 都只做本地产物。
