# 口播稿四关审读

审读一篇口播逐字稿的传播设计:它能不能让人停下、听下去、记住、传播。对象可以是 ray-kb 自产内容包里的逐字稿,也可以是用户直接给的裸稿。

## 与其他检查的分工

| 检查 | 管什么 | 类比 |
|------|--------|------|
| `oral_script_check.py` | 结构、来源指纹、时长估算、句长(机器可判) | 验房:面积和消防 |
| 衔接检查(如 dbs-script-flow) | 段与段是否丝滑,哪一秒跟不上 | 每层楼梯有没有断 |
| 四关审读(本文件) | 传播设计:停下、听下去、记住、传播 | 这房子有没有人想进来、想住下、想介绍给朋友 |

三层互不替代。审读不要求先通过脚本;但 ray-kb 自产内容包交付前,脚本与四关都要过。

## 核心原则

1. 四关是串联电路,先坏的那关决定命运:停不下来就没有播放,听不下去就没有完播,记不住就没有回响,传不动就没有增长。报告永远从第一关开始。
2. 只改"怎么说",不改"说什么"。判断、事实、数字、案例全部保持原样。审读对事实不设岗:默认稿内事实已在母稿管线核定,真伪不核对、不质疑、不评论;修改数字或事实的请求不属于审读,指回母稿与 `ray-writer`——不是因为怀疑,而是因为那是另一道工序的活。审读自己也不生产事实,不顺手补一个"更可信"的数字。
3. 修复建议必须能直接念出来,不给书面语方案。
4. 不过度诊断:整体过关就说过关。宁可漏掉小建议,不把高风险淹没在一堆小问题里。
5. 保持作者语气。改写不许把稿子改出通用 AI 解说味。
6. 判断某段"多余"之前先问:删掉它,观众在前一个关键节点能不能自己脑补出具体含义?脑补不出来,它就是论证的肉,不是赘肉。

## 审前确认

1. 拍摄方式:纯口播还是白板/字卡?编号清单和"划重点"类提示在白板视频里是视觉优势,不是病。用户没说就问一句。
2. 目标观众是谁?第二关的术语判定和第三关的例子判定都依赖它。用户没说时从稿子推断,并在报告里写明假设。
3. 裸稿(没有母稿)时,说明本次只审传播设计,事实真伪不在范围内。

## 第一关 停下(开场前 140 字)

理论依据:信息缺口(Loewenstein)、图式违背。

- 前三句打破了观众的哪个预设?写不出来 = 🔴。
- 缺口开在"差一点就知道"的位置吗?全然陌生没人在乎,接近常识没人好奇。
- 脱敏开场词("AI 时代""众所周知""今天给大家聊聊""最近很火")= 🟡 起步。
- 反预期之后有没有给出能自洽的新解释?只有惊悚没有解释,观众会用"这人瞎说"消解失调,不会更新认知。

常用修法:把全稿最强的命名或反直觉判断的影子前移;答案后置,先立缺口再还债。

## 第二关 听下去(全程)

理论依据:蔡格尼克效应(开环)、认知负荷、加工流畅性。

- 开环清单:列出每个悬念的打开点和闭合点。开了不闭 = 🔴(承诺违约);全稿无环 = 🟡(线性稿,全靠内容硬扛)。
- 断裂点:上段结尾到下段开头,观众能否自然明白为什么要讲这段?断裂 = 🔴。
- 密度节奏:连续三句以上抽象论述、没有例子或画面 = 🟡;同一个意思换说法反复讲 = 🟡。
- 数字呈现:先给意义再给数("一边关门,一边开门"之后才是 4%)。裸数字连发 = 🟡。
- 对冲句位置:诚实的限定("只是美国数据""不能全怪 AI")要合并成一句、放在证据之后一次说完;拆开连发或紧跟势能高点 = 🟡。
- 术语裸奔:目标观众语言游戏里没有的词,出现后一句之内没有人话解释 = 🟡。

## 第三关 记住(离场时)

理论依据:双重编码、生成效应、峰终定律。

- 中心判断有没有一个两到四个字、观众能原样复述的名字?对照 frontmatter 的 `central_judgment`。
- 双重编码:逐条列出没有配画面(场景、案例、比喻)的关键判断,它们是裸奔的。
- 生成效应:全稿至少一处让观众自己迈半步(设问、停一拍、再揭示)。零处 = 🟡。
- 峰值句是哪一句?找不出来 = 🔴,这稿没有峰。
- 终值:最后一拍是不是全稿前三强?"总结式""认命式"低唤醒收尾 = 🔴。

## 第四关 传播(离场后)

理论依据:STEPPS(社交货币、情绪、实用价值)、高唤醒情绪、ELM 双路径。

- 社交货币:观众能带走哪句话、哪个词去讲给别人?转发这条的人会显得聪明吗?
- 情绪档案:列出全稿唤醒的情绪。敬畏、愤怒、焦虑、惊奇是高唤醒,助传播;悲伤、认命是低唤醒,抑制转发。重点看结尾落在哪一档。
- 实用价值:唯一结尾动作是否具体到"今天就能做"?
- 双路径顺序:开场先用外周信号(冲突、画面、节奏)留人,再进中央论证;一上来就摆论据 = 🟡。

## 维特根斯坦透镜(第二遍,深改时用)

四关看的是机制,透镜看的是语言本身。七问:

1. 面相转换:这稿给了观众新事实,还是让旧事实换了一副面孔?后者才配叫"突破认知"。
2. 语言游戏:逐词过一遍,目标观众的棋盘上有这枚棋子吗?没有的词,要么换,要么当场翻译。
3. 生活形式:每个例子在观众的生活里有原型吗?给宝妈举硅谷创业,语言全通,理解为零。
4. 私人语言:哪句话只有作者自己知道在说什么?没有公共判据的"很重要""有价值""意义重大"全部点名。
5. 显示与言说:圈出所有"我想强调""这说明了一个道理"——该显示的被言说了,把宣布改成展示。
6. 命名:观众离开时,词汇表里多了哪个词?一个都没有,传播力上限就低。
7. 梯子:听完之后观众记住的是钩子还是判断?钩子喧宾夺主 = 技巧过量,拆梯子。

## 输出格式

1. 四关状态表:关 / 状态(✅ 🟡 🔴)/ 一句依据。
2. 问题清单:按 🔴→🟡→🟢 排列。每条 = 位置 + 原文引用 + 所属关卡与理论依据 + 能直接念的修法。
3. 整体评估加一句话决断:哪几关必须修才值得开机,哪些改不改都行。
4. 固定追问:"要直接帮你标记式改稿吗?保留你的原文,用删除线和 🆕 标出改动。"诊断完主动问,但用户不确认就不改。

## 标记式改稿协议(用户确认后)

1. 永不抹除原文。原地标记:`~~建议删除的原文~~` 紧跟 `🆕 替换或新增`;自己撤回判断用 ⚠️ 标注并还原,不当作没发生。
2. 只动呈现层:顺序、钩子、过渡、命名、画面化、结尾。不动事实、判断、数字、案例真伪。
3. 改完给改动清单表(位置 / 类型 / 说明),末尾一句话决断,分清必改与可选。
4. 多轮反馈追加标记,不覆盖历史。
