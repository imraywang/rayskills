# 口播结构：70 分开场 + 连续小高峰 + 快收

传统的“铺垫—上升—高潮—回落”在短视频里不管用：观众在铺垫阶段就划走了。口播按下面三条排，观点型、叙事型都适用。

1. **开场就在 70 分。** 第一句把观众直接扔进事情中间：一个说满的判断、一个已经发生的冲突、一个反常的结果，不交代背景、不自我介绍、不“今天我们来聊”。接下来 5–10 秒内冲到第一个高峰（90 分）。第一个高峰从三种里挑：反差时刻、反常识观点（作者站队的那一下）、惊人的数字。
2. **每 20–30 秒一个小高峰。** 高潮不放在中间，而是一个接一个叠：讲完一个峰，释放一下（举例、解释、讲经过），然后再冲下一个。按检查脚本用的语速（每分钟 220–260 字）算，大约每 80–120 字要有一个峰，可以是新的反差、新的站队判断、新的数字、故事的转折。连续一大段只在解释、没有峰的地方，就是观众划走的地方，改稿时先砍或者补峰。叙事型的峰就是故事里的转折。
3. **结尾收得快。** 最后一个峰就是收尾：观点型给观众明天做得出来的动作，叙事型落一句作者的判断。之后马上收，不总结全篇。要不要加关注、评论或领取之类的引导，看作者档案；档案没写就不加。
