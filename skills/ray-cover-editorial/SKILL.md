# Ray Cover Editorial

把一致性放在文章个性之前：所有封面使用同一种画种、同一组颜色和同一种“左右叙事、中央呼吸”的构图，每篇只更换文章场景。

本 Skill 是 `ray-cover` 的独立兄弟流程。不要改写、调用或继承旧流程的“每篇选择风格 + 完整标题直出”规则。

## 固定交付公式

`固定编辑版画 + 左右叙事 + 中央呼吸区 = 无字 base 图`

- 底图固定使用 `ray-editorial-engraving`。
- 文章场景拆成互相关联的左右两个视觉锚点，不做镜像对称。
- 中央保留低细节背景和纸张纹理，不放脸、关键物体或高对比焦点。
- 中央不是白洞：可以保留天空、墙面、地面、阴影或版画纹理。
- 默认只交付无字 base 图，不自动加标题、`RAY`、关键词、Logo 或遮罩。

## 工作流

### 1. 读取文章依据

读取完整正文；若有成稿包，同时读取一句话判断和核心冲突。文章判断尚未稳定时，先交回 `ray-writer`，不使用漂亮底图替文章决定主题。

只提取：

- 一句话判断
- 一个能被画出来的完整场景
- 左右两个互相关联的视觉锚点
- 一个最小朱砂红焦点

不要为封面另写一套观点，也不要虚构作者经历、人物或产品行为。

### 2. 固定画种与构图

每次生产都读取 [visual-system.md](references/visual-system.md)，使用同一个视觉语法：古典科学版画线条、当代丝网印刷色块、深靛蓝、暖米白与朱砂红、纸张颗粒、左右叙事、中央呼吸区。

不得在提示词中写 a16z、Every、elsewhere 或其他品牌名。参考只用于理解“一种出版物坚持一种画种”，成品必须是 Ray 自己的系统。

### 3. 建立简短任务包

按 [brief-schema.md](references/brief-schema.md) 写 `cover-brief.json`，然后运行：

```bash
python3 scripts/brief_check.py <cover-brief.json>
```

任务包只描述文章依据、底图场景、固定画种、中央呼吸区与需要的平台，不加入任何文字、字标、Logo 或遮罩设置。

### 4. 各平台分别生成无字底图

使用系统图片生成能力为每个平台分别生成底图。提示词必须写清：

- 平台比例和目标尺寸
- `ray-editorial-engraving` 的固定媒介、颜色和纹理
- 本篇唯一变化的完整场景
- 左右视觉锚点属于同一个故事，不拼成两张独立海报
- 中央约 26%–32% 宽度保持低细节，只保留连续背景和版画纹理
- 禁止任何文字、字母、数字、Logo、品牌、水印、摄影感和 3D 渲染

公众号、普通 X 与 X Article 共用画种和场景，但各自生成对应比例，不拿一张底图跨比例硬裁。

### 5. 交付到 base 图即停止

默认不运行 `scripts/compose_editorial_cover.py`，不叠加遮罩，也不根据文章标题自行加字。标题、关键词或 Logo 由用户后期处理。

只有用户在同一任务中明确要求“请替我完成排字”时，才把排字视为额外步骤；不能因为文章标题已经存在就自动执行。

### 6. 检查单张与系列一致性

逐张打开原图和 400–420px 缩略图，检查：

- 底图确实属于固定编辑版画画种，没有滑向油画、摄影、3D 或通用 AI 海报。
- 左右两个视觉锚点共同表达文章内容，不是无关元素堆放。
- 中央有安静的深色或低细节呼吸区，但仍保留连续背景、地面和纸张纹理。
- 中央没有脸、关键物体、朱砂红焦点或无法被后期标题覆盖的高对比细节。
- 全图没有生成文字、字母、数字、Logo、签名或水印。
- 没有自动遮罩或统一压暗，底图保留原始色彩和细节。
- 尺寸正确，左右主体没有被边缘裁坏。

已有三张以上封面时，运行：

```bash
python3 scripts/make_contact_sheet.py <对比图.png> <base图1> <base图2> <base图3>
```

只看缩略图阵列：它们应像同一本出版物的不同文章，同时都具有左右叙事和中央呼吸感。

### 7. 落盘与边界

默认保存到：

`<vault>/60-素材/10-图片/10-封面/<YYYY-MM-DD-主题>/`

保留：

- `cover-brief.json`
- `base-<platform>.png`
- `contact-sheet.png`（达到三张系列样本时）
- `manifest.json`

平台尺寸读取 [platform-output.md](references/platform-output.md)。只制作本地无字底图，不打开平台后台，不创建草稿，不自动发布。

## 交付

只交付所需平台的 base 图和任务包。用一句话说明本篇左右分别画了什么，并明确“已停止在无字 base 图，未加标题、字标、Logo 或遮罩”。
