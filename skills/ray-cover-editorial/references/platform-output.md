# 平台输出

这些尺寸是当前生产默认值；平台规则变化时重新核对。

| 平台 | 尺寸 | 比例 | 中央呼吸区 |
| --- | ---: | ---: | --- |
| 公众号 | 2100 × 900 | 21:9 | 宽度约 26%–32%，低细节背景 |
| 普通 X | 1600 × 900 | 16:9 | 宽度约 26%–32%，低细节背景 |
| X Article | 1600 × 640 | 5:2 | 宽度约 26%–32%，低细节背景 |

## 规则

- 每个平台分别生成无字底图，不能把 16:9 base 图直接裁成 5:2。
- 左右主体必须在对应比例中重新组织，中央继续保持低细节呼吸感。
- 只输出 base 图，不自动加标题、字标、Logo、遮罩或文字底板。
- 缩到 400–420px 宽时，仍能看出左右叙事和中央呼吸结构。
