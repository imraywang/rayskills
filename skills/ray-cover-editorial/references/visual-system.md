# Ray 编辑版画视觉母版

## 唯一画种

内部名称：`ray-editorial-engraving`

这是一种 Ray 自有的当代编辑版画：借用古典科学插图、铜版画和木刻的线条语言，再用克制的现代丝网印刷色块组织画面。不要引用或模仿任何具体出版物名称。

## 固定视觉 DNA

- **线条**：细密雕版线、交叉排线、黑色轮廓与局部网点。
- **色板**：墨黑 `#151515`、暖米白 `#F1E7D2`、深靛蓝 `#183B66`、朱砂红 `#D85C41`。
- **用色**：每张图以墨黑和米白为基础，深靛蓝为主色，朱砂红只做一个小面积焦点。
- **材质**：可见纸张纤维、轻微油墨渗透和套印偏差；不做肮脏旧化。
- **空间**：一个完整场景，强轮廓、清楚前后景，不做密集信息图。
- **对象**：最多三个主要对象；人物可以出现，但不冒充文章中未出现的真实人物。

## 固定构图：左右叙事，中央呼吸

- 左右两侧各有一个视觉锚点，共同讲清同一个文章隐喻。
- 两侧不做镜像对称；大小、远近和密度可以不同。
- 画面中央约 26%–32% 宽度保持低细节，不放脸、关键物体或朱砂红焦点。
- 中央不是纯色挖空：延续天空、墙面、地面、阴影、纸张纤维和版画排线。
- 留白服务节奏与后期排字，但底图本身不生成、暗示或摆放任何文字。

## 每篇唯一变化

只替换一条完整场景描述，并说明左右两个锚点如何共同表达文章判断。例如：

> 左侧是一位拿着图纸的建造者和待装材料；右侧是一间正在组装的模块化办公室；中间只延续深靛蓝背景与地面纹理。

不要改画种、色板、纹理和中央呼吸结构。抽象主题也要落成一个能看见的场景，避免发光大脑、芯片、机器人头像、漂浮界面和无意义几何。

## Base-only 边界

- 默认不加标题、`RAY`、关键词、作者、日期或 Logo。
- 默认不加全图遮罩、局部渐变、暗角或文字底板。
- 输出保留底图原始色彩和细节，用户自行完成后期排字。

## 禁止漂移

- 摄影、电影剧照、油画、水彩、3D 渲染、卡通贴纸。
- 霓虹科技、赛博朋克、发光芯片、全息 UI。
- 多块卡片、图表标注、箭头网络和密集小字。
- 生成的文字、字母、数字、Logo、签名和水印。
- 在提示词中出现活跃品牌、艺术家或出版物名称。

## 固定提示词骨架

> 为文章封面生成一幅无字的当代编辑版画底图。使用古典科学插图和铜版画式细密黑色排线，结合克制的现代丝网印刷色块；固定色板为墨黑、暖米白、深靛蓝，只有一个小面积朱砂红焦点；可见纸张纤维和轻微套印偏差。画面是一个连续场景，左右两侧各有一个互相关联但不对称的视觉锚点，共同表达文章判断。中央约 26%–32% 宽度保持安静和低细节，只延续背景、地面、阴影与版画纹理，不放脸、关键物体或高对比焦点。全画面无任何文字、字母、数字、Logo、签名、水印、摄影感、3D 渲染、霓虹科技或漂浮界面。场景内容：{subject}。
