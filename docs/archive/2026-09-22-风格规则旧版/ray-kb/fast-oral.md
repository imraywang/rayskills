# 原生快速口播

当内容从灵感、现场观察、咨询案例或对话中的初步判断直接开始，而不是从一篇已经核验的完整长文再分发时，使用本模式。目标是缩短“想到”与“开机录制”之间的距离，同时保留事实边界、录前检查和录后学习。

## 完成形态

整个生产阶段只保留一份活跃文件：`<vault>/10-创作/20-口播草稿/<标题>.md`。它既是判断与检索记录，也是可直接录制的母稿。

不要为了兼容长文模式而额外创建：

- 候选选题卡；
- 写作任务或 `content-pack`；
- 带七个固定章节的衍生口播包；
- 指向自己的 `source_draft` 或自引用内容指纹。

如果用户本来就有候选、知识笔记或调研材料，可以链接复用，但不复制一套轻量版本。

## 快速判断

按顺序确认四件事：

1. **只讲什么**：用一句话写出 `central_judgment`，删掉后整条内容就不成立。
2. **为什么会停下**：确定一个反常识、变化或具体冲突作为最终开场；可以在对话中比较多个开场，但文件只保留采用项。
3. **证据是否够**：先检索本地知识库；涉及近期公司、产品、人物、数据或事件时，再联网核对最新事实。
4. **边界在哪里**：明确本条不展开什么、最强反方是什么、哪些内容仍然未知。

任一情况成立就退出快速模式：无法压成一个中心判断；需要多个章节才能解释；证据缺口会改变结论；用户希望同时生产完整图文母稿。

## 事实依据

在 frontmatter 记录 `fact_basis`：

- `local-knowledge`：判断主要来自知识库已有笔记或历史内容；“检索与事实边界”至少保留一个有效 wikilink。
- `web-research`：主要依赖本轮联网核对；填写 `research_checked_at`，并至少保留一个原始网页链接。
- `personal-observation`：主要来自 Ray 本人的现场观察或已确认经历；写清观察范围，不能把单一案例说成普遍事实。
- `mixed`：联网来源与本地知识或个人观察共同支撑判断；填写 `research_checked_at`，至少保留一个原始网页链接，并补充对应知识链接或观察范围。

联网检索只补当前判断需要的证据，不把检索过程全部塞进口播。事实、来源作者观点、Ray 的判断和未知项分开写。

## 唯一母稿

使用知识库里的 `50-系统/30-模板/快速口播母稿.md`。最小 frontmatter 包含：

```yaml
kind: oral-script
status: draft
production_route: fast-oral
central_judgment: "观众看完只记住的一句话"
fact_basis: local-knowledge
research_checked_at: ""
target_duration_seconds: 180
video_format: A-roll
recording_status: pending
```

正文只保留五段：

1. `这次只讲一个判断`：中心判断、最终钩子、不展开内容和最强边界。
2. `检索与事实边界`：本地知识、最新事实、个人观察与未知项。
3. `口播正文`：只放能直接念的文字，不混入镜头说明、列表或来源。
4. `录前检查`：简短记录“停下、听下去、记住、传播”四关结论和必须改的唯一问题。
5. `录制与发布收尾`：状态、录后对照、发布确认、反馈和知识回写。

需要画面时再把已确定的口播交给 `ray-broll`；不要为了通过快速口播检查，提前制造完整拍摄表或图片长文方案。

## 检查与录后学习

完成逐字稿后运行：

```bash
python3 scripts/oral_script_check.py <快速口播母稿.md>
```

脚本通过后，再按 [口播稿四关审读](script-review.md) 做一次简短判断。没有真实朗读时，只报告估算时长。

用户给出实际录制稿时，按 [录后对照与表达学习](recording-feedback.md) 处理：先保留生成稿版本或内容指纹，再把实际录制文本作为最终表达真源；详细 difference 可以进入当前选题的调研记录，但生产阶段仍只有这一份活跃母稿。录完只标记 `recorded`，不能推断已经发布。

## 发布回流

确认公开发布后再把最终逐字稿移到 `40-发布/50-口播视频/`，并完成：

- 确认实际发布平台；公开链接和准确发布时间可以留空；
- 建立正式反馈记录；
- 将可复用观点回写长期知识，或明确 `not-needed`；
- 保留剩余角度，或明确 `not-needed`；
- 最终录制稿和生成稿的 difference 已有可追溯入口。

`recorded`、已生成平台草稿和公开发布是三个不同状态，不互相推断。
